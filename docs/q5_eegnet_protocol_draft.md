# Q5：四类 EEGNet 公平对照协议草案（尚未运行）

更新：2026-09-23。依据 [EEGNet 原论文](https://arxiv.org/pdf/1611.08024) 与 [Braindecode 官方模型文档](https://braindecode.org/stable/generated/braindecode.models.EEGNet.html)。本文件是下一阶段可评审的协议草案，**没有训练、分数、图或投稿主张**；实施前须固定依赖、时间预算和最终参数版本。

## Research Question

在 Q4-E001 完全相同的 BNCI2014_001 四类试次和九人外层 LOSO 上，轻量 EEGNet 是否比固定的宽频 CSP8+LDA 获得更高、更均匀的逐人 BA？如果没有，差别是否来自高分/低分受试者和不同动作类别？

## 数据与信息预算

- 用 Q4 的 5184 个 `sample_id`、标签和 expert flag；每折一整人的两会话 576 trial 外层测试，其余八人 4608 trial 是唯一可学习数据。
- 22 EEG、250 Hz、[trial+2.5, trial+5.5) 秒的 750 点、4–40 Hz 四阶零相位 Butterworth。使用固定系数 $10^6$ 把伏特换算微伏，不从目标人估计均值、方差或空间变换；输入张量 `(trial,22,750)`。
- 保留全部专家标记试次为主测试；标记/未标记只在预测完成后分层。不按外层目标分数、标记或标签选择 epoch、频带、种子或超参。

## 模型与拟合

- 选择当前冻结版本的 `braindecode.models.EEGNet(n_chans=22, n_outputs=4, n_times=750, F1=8, D=2, F2=16, kernel_length=64, drop_prob=0.25)`，其余构造参数、Braindecode/PyTorch 版本和可训练参数数目实际保存。官方 API 会变，运行时先做输入/输出形状和固定种子的烟雾测试。
- 交叉熵损失，Adam 初始学习率、权重衰减、batch size、最大 epoch 和调度规则必须**在首个外层测试成绩出现前锁定**，不得按外层目标调参。BatchNorm 统计仅在训练模式由源 trial 更新，目标预测时切换 `eval()`。
- 超参数或训练 epoch 若需数据选择，在每个外层八名源人之内作受试者分组验证。内层模型必须从头初始化，只用内层训练人的数据更新全部网络参数与 BatchNorm；内层验证人仅用于选择/早停。用锁定的源内规则确定最终 epoch，再从头在八名源人上训练，最后一次性预测外层目标。
- 最终训练至少 3 个预先固定的随机种子。每个种子分别保存 epoch 学习曲线、源内验证和最终外层预测；主报告可先按每位被试各种子 BA 均值汇总，并展示种子离散性，但不能把 9×3 次模型当成 27 个独立受试者。

## 与传统对照的公平性

共享 sample ID、时间窗、频带、22 EEG、全部试次政策、LOSO、主指标和逐人报告。传统模型 Q4 无源内调参；EEGNet 的训练轮数或调度若经源内选择，解释时承认选择预算不同并报告算力。主比较按每名目标受试者的配对 BA 差，而非拿论文中不同二/四类、不同预处理、不同目标数据预算的最高值作排名。

## 验收与资源

本机独立 Python 环境目前没有 `torch`、`braindecode` 或 `skorch`；显卡是 Intel Arc，不能假定 CUDA。下一步先锁定可兼容的 PyTorch/Braindecode 版本，做单批正反向训练和一个目标人的运行时间测量，再估算九折×内层验证×多种子的总耗时。正式运行必须保留失败实验目录，输出数据、代码/锁文件 SHA-256、逐 trial 预测、目标各类混淆矩阵和独立验证报告。任何被试准确率、总体优势或神经机制结论都以真实跑完且验收后为准。

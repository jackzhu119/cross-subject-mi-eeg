# 对历史探索性统计的解释补充

日期：2026-09-22。适用于 P2、P3、P4 以及对应两份论文样例；不改动原预测与结果数值。

九名受试者是九个不同的人，应以逐人结果为报告单位，不能用 trial、run、session 扩大样本量。但 LOSO 各折训练集合重叠，因此由九个拟合模型产生的九个测试分数不应未经论证称为九次完全独立的算法实验。

已有 percentile bootstrap 是对固定九个逐人配对差重抽样，没有在每次 bootstrap 里重新抽取训练人群并重训模型。它描述当前已计算分数的异质性，未完整估计训练样本变化、模型选择与折间依赖带来的不确定性。P2 的 512 种符号翻转是有限枚举的参考计算；“精确枚举”不等于其交换性/独立性假设已满足，也不使总体推断自动精确。

因此保留已有区间和 p 值供审计，但将其标为探索性条件参考。它们不能作为方法优越性的确认性检验。今后的主要证据先报告九个配对差、均值、标准差和范围；正式推断方案应结合冻结协议、训练随机性、额外受试者/数据集和适合其采样结构的方法。

这一限制与交叉验证训练集合重叠造成方差估计困难的经典分析一致，但该理论论文不是对本项目 LOSO 设计给出某个自动适用的校正公式。[Bengio & Grandvalet, 2004, JMLR](https://jmlr.csail.mit.edu/papers/v5/grandvalet04a.html)。

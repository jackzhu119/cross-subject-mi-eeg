# 外部数据集验证方案：独立复现与零样本跨数据集迁移

日期：2026-09-23。状态：**仅方案与官方资料核对；尚未下载 PhysioNet 数据，尚未运行任何外部实验，也没有外部准确率。** 本文不把计划写成实验结果。Q4-E001 是 BNCI2014_001 的四分类九人 LOSO，不能直接拿来与下面的二分类数值相减。执行前应在代码、配置和日志中冻结最终版本；若审计发现必须改动，记录改动原因和新版本。

## 1. 两个不同的研究问题

| 实验 | 训练数据 | 测试数据 | 能回答什么 | 不能声称什么 |
| --- | --- | --- | --- | --- |
| A. 独立数据集上的同协议方法复现 | PhysioNet EEG Motor Movement/Imagery 中其他受试者 | PhysioNet 一名完整留出受试者，逐人轮换 | 锁定的 CSP、空频特征与 EEGNet 方法在另一采集体系的左右手想象任务上，是否仍呈现相似的相对表现与个体差异 | 这不是 BNCI 训练模型的直接迁移，也不是 Q4 四分类成绩的同任务复制 |
| B. 零样本 BNCI→PhysioNet 迁移 | BNCI2014_001 的左右手想象受试者 | 从未用于拟合、选参或早停的 PhysioNet 左右手想象受试者 | 一个只在 BNCI 学到的模型，跨采集设备、实验协议和受试者群体能否直接泛化 | 这不是 PhysioNet 内 LOSO；任何目标域训练、目标标签选参或以目标分数挑预处理都会破坏“零样本”定义 |

两个实验须分别编号、分别存预测和报告。先完成与外部任务匹配的 **BNCI 左右手二分类重新基线**；既有 P2/P3 是先前探索性、不同试次政策和频带的结果，不是自动公平的外部参照。A、B 都不使用 PhysioNet 执行运动的 run 或静息 run 作为“想象”样本。

## 2. 可核实的数据事实与不兼容处

[BNCI2014_001 的 MOABB 官方说明](https://moabb.neurotechx.com/docs/generated/moabb.datasets.BNCI2014_001.html)列出 9 名受试者、4 类（左手、右手、双脚、舌）、22 个 EEG 通道、250 Hz、两会话；本地 Q4 的 5184 个四分类试次及处理窗口另见 `docs/q4_e001_results.md`。[PhysioNet 官方数据页](https://physionet.org/content/eegmmidb/1.0.0/)说明其 EDF+ 记录为 64 EEG、160 Hz、14 个 run；[MNE 官方 run 表](https://mne.tools/stable/generated/mne.datasets.eegbci.load_data.html)明确 4/8/12 为**左右拳运动想象**，6/10/14 为**双拳/双脚运动想象**。PhysioNet 注释 `T0` 为静息，`T1`、`T2` 的含义依 run 而变：在 4/8/12 中分别为左拳、右拳，在 6/10/14 中分别为双拳、双脚。不能仅凭事件码跨 run 合并标签。其公开条款标为 Open Data Commons Attribution License v1.0；正式使用时按数据页要求注明数据集和原始 BCI2000 工作。

PhysioNet **没有 BNCI 的“舌想象”类别**；“双拳”也不是 BNCI 的“舌”。因此它不能验证 Q4 的原样四分类问题。把 4/8/12 的左、右拳与 6/10/14 的脚硬拼成“三分类”还会使类别与 run/视觉提示类型混杂，不列为主分析。这里最清楚的共同任务只有 4/8/12 run 的左手对右手二分类；其机会水平为 50%，与 Q4 四分类的 25% 不同。PhysioNet 页面仅描述 EEG 和注释，不能假定存在与 BNCI 等价的 EOG 通道或专家伪迹标记；EOG 回归及“专家标记试次”分层不能无条件照搬。

## 3. 先做元数据审计，再冻结最终可运行协议

通过 [MNE `eegbci.load_data`](https://mne.tools/stable/generated/mne.datasets.eegbci.load_data.html)只定位/获取预定受试者的 4/8/12 run，用 [MNE `read_raw_edf`](https://mne.tools/stable/generated/mne.io.read_raw_edf.html)逐 run 读取；[MNE `eegbci.standardize`](https://mne.tools/stable/generated/mne.datasets.eegbci.standardize.html)可统一 PhysioNet 的通道名称。**本方案写成时尚未执行下载**。首批审计表必须保存每个文件的 URI、大小、SHA-256、受试者、run、实际采样率、通道名/类型、参考信息、`T0/T1/T2` 数量、各注释持续时间、文件末尾可用时长及读取异常。检查 BNCI 与 PhysioNet 的真实同名电极交集，再锁定有序的共同 EEG 电极清单；这里不虚构交集数目或外部试次数。若个别人的文件、事件或采样率异常，以审计为准，事前写明可重复的纳入/排除规则，保留所有异常记录。

共同任务候选处理链如下，**窗口须经不看分类结果的事件持续时间审计后才可最后冻结**：

1. 标签只取 BNCI 左/右手与 PhysioNet 4/8/12 的 `T1=left`、`T2=right`；忽略 `T0` 和其他 run。以事件起点而非文件起点切片，保留 `dataset/subject/session_or_run/trial/event_time/label` 清单；不根据目标预测或类别差异删 trial。
2. 用同一有序电极交集训练和测试两个数据集，**重新训练**二分类 CSP 与 EEGNet；Q4 的 22 通道四分类模型参数不能直接载入。优先预先声明在交集电极上进行同一确定性的共同平均参考；其运算不学习跨试次统计量，但须记录原采集参考和这一变换，不能看测试准确率后切换参考策略。
3. 两域分别在连续 run 上应用同一固定 4–40 Hz 带通，再将 BNCI 250 Hz 抗混叠重采样至 160 Hz；PhysioNet 保持其审计确认的 160 Hz。优先采用 cue/任务开始后 `[0.5, 3.5)` s、480 采样点，以对应本地 Q4 的 cue 后时窗；**仅当每个拟纳入事件都支持该长度时**才采用。若不支持，先在审计报告中明确短窗及两域统一重提取，不得用目标分类分数挑窗。跨 run 不拼接后再滤波或切片，以免边界污染；事件时间与重采样后的采样点映射必须测试。
4. 固定物理单位（MNE EEG 伏特转微伏特可乘 `1e6`），并记录实际数据单位与转换。若需数据驱动的通道均值/方差、坏道阈值、伪迹排除、特征选择、CSP、缩放、早停或校准，所有估计严格限于各实验的训练来源；B 中不得用 PhysioNet 全体信号估计目标域标准化或对目标人自适应。固定、逐 trial/时点的参考运算应与目标域统计拟合明确区分。
5. 对 A/B 的 CSP、空频和 EEGNet 用**同一 trial 清单、同一标签、同一滤波/采样/通道/窗口**。如果特定模型需不同形状，仅做预先声明的重排，不改变信息量；比较时单列训练预算、参数量、特征维数和计算成本。任何视觉检查导致的规则变更都记日志并说明确认性地位受损。

## 4. 划分、训练与信息隔离

**A：PhysioNet 内部 LOSO。** 审计后固定实际合格受试者集；外层一次留出一整名 PhysioNet 受试者（其 4/8/12 全部 run），剩余受试者做训练。模型与超参数在来源受试者内部按受试者分组验证，不以留出人的分数挑频带、窗口、CSP 维数、坏试次阈值或 epoch。最终模型只在来源受试者重拟合，然后预测留出人一次。每种方法分别保存逐人、逐 seed 成绩；不能把不同随机种子当作新受试者。

**B：真正的 BNCI→PhysioNet 零样本。** 在只查看 BNCI 数据及不含性能信息的 PhysioNet 元数据后，冻结共同通道/窗口/预处理/模型与种子。全部模型参数和任何训练型转换只由 BNCI 左右手样本估计；可用 BNCI 内部分组验证完成参数/训练 epoch 选择，再在预定 BNCI 来源集重训。冻结的同一个模型直接应用到全部合格 PhysioNet 目标人，既不重训也不校准。若预测后想调参，保留首次盲测为主分析，后续标记为新探索，不把它称为独立确认。B 可以附带 **反向 PhysioNet→BNCI** 作为新的预先固定验证，但需独立标注方向与训练来源；不能把双向成绩合并为单一“跨数据集准确率”。

两种划分都要自动断言训练/测试的 `dataset+subject+trial` 标识无交集；内层验证不得复用包含验证人的 CSP、缩放或网络早停拟合。保存拟合清单、源码/环境版本与哈希、输入文件哈希、冻结配置、随机种子、完整逐 trial 真值/预测/概率、失败及警告、独立重算指标报告。若一个数据集原始通道缺失、相同窗口无法提取或标签定义发生冲突，在看外部成绩之前暂停并发布协议修订；不是无声删掉困难的受试者。

## 5. 评价与结论边界

主指标为**每名目标受试者的 balanced accuracy**（两类召回率平均），随后报告受试者等权 mean、样本 SD、范围和每人结果；另给 accuracy、macro-F1、两类召回、混淆矩阵、每 seed 离散性与缺失/排除 trial 数。A 比较同一 PhysioNet 目标人上的模型差；B 报告每个 PhysioNet 目标人的零样本表现，可与按完全相同匹配协议得到的 BNCI 内 LOSO 和 A 的 PhysioNet 内 LOSO 作**描述性**差距分析，不将不同训练量/协议下的分数差归因于单一“域偏移”。统计与不确定性以受试者为单位；LOSO 训练集高度重叠，试次不是独立受试者。

结果即使优于基线，也只说明该锁定任务及两个采集体系下的证据。设备/电极、原始参考、160 对 250 Hz、视觉提示与任务执行说明、数据年代、试次质量和类别组成都是潜在域差异；这一设计不能仅凭成绩证明“傅里叶滤波去掉了干扰信号”或恢复了神经真实信号。PhysioNet 无对等 EOG/专家标记时，伪迹机制须另找可测代理与神经保真检验，不能把分类准确率或 EEG–EOG 相关性当成去伪迹证明。

## 6. 实际执行顺序与验收点

1. 完成当前 BNCI 四分类 Q5 EEGNet 公平基线与独立核验，不用 Q5 的外层目标人选择模型版本。
2. 在 BNCI 内建立与 PhysioNet 对应的**二分类共同电极/160 Hz/共同窗口**新基线；配置、受试者内层验证、模型预算和预定主比较先冻结。
3. 仅下载审计所需的 PhysioNet 4/8/12 run，完成文件与事件清点；据审计冻结所有受试者、trial 纳入规则和处理链，并在任何外部模型结果前保存带时间/哈希的协议版本。
4. 运行 A 并独立核验逐 trial 与逐人指标；再以单独编号运行 B，核验没有任何 PhysioNet 训练型拟合。顺序不会使已查看的 A 结果变成 B 的“完全盲”研究：若 A 结果影响 B 的参数选择，必须坦承 B 为探索性，或先同时冻结两套完整协议。
5. 对照预写假设解释每人差异、类别混淆及失败案例，最后才判断是否足以构成外部确认或可投稿结论。

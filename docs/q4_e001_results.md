# Q4-E001：完整四类 source-only LOSO 传统方法实验

日期：2026-09-23。**真实运行已完成且独立验证通过**。主入口：`outputs/Q4-E001/status.json`、`config.json`、`trial_metadata.csv`、`fit_manifest.csv`、`predictions.csv`、`per_subject_metrics.csv`、`summary.csv`、`validation_report.json` 与 `figures/`。以下百分数均来自这些文件；该实验是看过此前二分类数据后的探索性固定本地协议，不是独立确认或公开预注册。

## 1. Research Question / Hypothesis

在完全未见的受试者上，固定的 4 Hz 滤波器组加多类 CSP，能否比单一 4–40 Hz 宽频多类 CSP 更稳定地辨别左手、右手、双脚和舌运动想象？预先的工作假说是可能改善，但允许负结果。次级问题是 72 维滤波器组经仅源端互信息保留 8 维后如何变化。

## 2. Dataset / Preprocessing

BNCI2014_001：九人，两会话，每人 576 个四类 trial，各类每人 144 个，总 5184；250 Hz、22 EEG。MAT trial-start 事件之后 [2.5,5.5) 秒，即 cue 后 [0.5,3.5) 秒，750 采样点。每条连续 run 分别经固定四阶零相位 Butterworth 滤波；一条 4–40 Hz 宽频或九条 4–8、8–12、…、36–40 Hz 窄频。无额外基线、重参考、重采样或 50 Hz notch。主结果纳入全部 5184 trial，488 个专家伪迹标记只作测试后分层；剩余 4696 个未标记。各受试者标记数为 22–142，分层并非随机或等大小人群。

## 3. Method / Train-Test Strategy

外层九折 LOSO：每折一名目标人的两会话 576 trial 测试，其余八人 4608 trial 训练。每频带的 MNE 多类 CSP 在源数据上以 OAS 类协方差拟合，取 8 个 log-power 分量；九频带合计 72 维。四种固定模型：宽频 CSP8+源标准化+收缩 LDA；宽频 CSP8+标准化+线性 SVM；九频带 CSP72+标准化+收缩 LDA；同一 CSP72 后在源训练集以互信息选 8 特征，再标准化+收缩 LDA。随机种子 20260922；未按外层目标成绩调参。九折总计 90 次 CSP 拟合和 36 次分类器拟合。这个实现是**滤波器组 CSP 变体**，不是 Ang 等 2012 方法的精确复现；72 与 8 维比较并不容量匹配。

## 4. Evaluation / Results

主指标为每个目标受试者的四类 balanced accuracy（BA），九人等权平均，`±` 为九人间样本标准差，**不是置信区间**。四类在每个目标人全试次均衡，故本实验全试次 BA 与 accuracy 数值相同；随机均衡基准约 25%。

相对宽频 LDA，九频带 LDA 的九人**配对平均差为 −0.93 个百分点**、配对中位差为 +0.35 pp、9 人中 5 人改善；S01 与 S06 的增益分别约 +13.72、+12.15 pp，但 S08/S09 下降约 −12.67/−15.97 pp。降低的被试间 SD 不能单独证明“稳健”，因为高分受试者也被拉低。MI8 平均相对宽频低 −7.68 pp，仅 3/9 人改善；这说明本次简单源端互信息筛选没有保住滤波器组的多类判别信息，并不证明 μ/β 频段无效。宽频 SVM 相对宽频 LDA 平均低 −1.54 pp。

四类聚合召回率（标签依次左手、右手、双脚、舌）分别为：宽频 LDA 43.67%、46.37%、39.43%、26.70%；九频带 LDA 40.59%、35.49%、29.94%、46.45%。分频方法改变了类别错误结构：舌分类明显上升，同时右手和双脚下降；不能仅用一个均值评价其机制。MI8 的双脚召回率为 11.73%，值得在下一个预定消融中检查特征维数、频段和类别不平衡的交互。

未标记/标记目标试次上，宽频 LDA 的逐人 BA 均值分别为 39.52%/34.79%，九频带 LDA 为 38.45%/35.55%。标记试次非随机，按专家标签选择的难度和人群各不相同；这些数字只描述试次分层，不能解释为“某方法去掉了干扰”。九折 MI8 共选择 72 个特征名额，其中 8–12 Hz 24 次、20–24 Hz 21 次、12–16 Hz 15 次；这是源端选择频段的分布，不等于频段有脑源因果效应。

## 5. 证据核验与局限

独立核验程序重算了 648 个指标数值，检查了九折 4608/576 的源/目标 ID、20,736 条逐 trial 预测、全部 4×4 混淆格、36 组标准化参数与源特征均值、18 个 MAT SHA-256 和 32 个启动源文件 SHA-256；`validation_report.json` 为 `passed`。11 个自动测试通过。两张科学图 `figures/fourclass_loso_subject_heatmap.png` 和 `figures/fourclass_loso_paired_differences.png` 已按结果 CSV 渲染并目检。原始运行花约 544 秒；MOABB 读取时出现 MNE montage 名称将弃用的 FutureWarning，当前不影响本版本输出，升级依赖后须重跑等价性检查。

目前**未证明滤波器组整体优于宽频 CSP**。主要限制：仅一个已在二分类阶段探索过的数据集、九名受试者、较低的四类分数与强个体差异；8/72 维和分类器容量不同；人工专家伪迹标记只用于离线分层；零相位处理不可直接部署在线；无外部验证、EEGNet 对照或事先锁定的机制消融。九折训练人群高度重叠，不把九个分数当作完全独立重复训练研究做简单显著性主张。

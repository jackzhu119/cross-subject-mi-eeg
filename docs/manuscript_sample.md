# 基于共空间模式的跨被试运动想象脑电解码：BNCI2014_001 上的可复现基线研究

> 2026-09-22 审计补充：本稿保留为历史探索性样例。LOSO 训练集合重叠，已有 bootstrap 和符号翻转数值仅作条件性描述，不能视为严格总体推断；详见 `docs/statistical_interpretation_addendum.md`。后续正式稿仅维护 `paper/outline.md`。

> 论文样例，研究范围为已实际运行的传统 CSP 基线。它不声称提出了新的跨被试改进算法，也不声称已完成 EEGNet、Filter Bank CSP 或跨数据集验证。作者、单位及伦理声明应由真实研究者在正式投稿时填写。主分析数值来自 `outputs/P2-E001/`，附加的事后敏感性分析来自 `outputs/P2-E002-ALLTRIALS/`；两者均经 `validate_csp_run.py` 独立复算与输入哈希校验。

## 摘要

**目的：**运动想象脑电（motor imagery EEG）解码在不同受试者间存在性能波动，未经严格受试者级划分的测试易高估泛化能力。本研究建立一个可复现的二分类传统基线，比较同一受试者内、跨会话及完全未见受试者三种评估情境。

**方法：**使用 BCI Competition IV Dataset 2a（BNCI2014_001）全部 9 名受试者的两次会话，仅保留左手和右手运动想象。采用 22 个 EEG 通道，对每个 run 施加固定 8–30 Hz 四阶 Butterworth 双向滤波，取提示后 0.5–3.5 s 的 3 s 片段，排除数据集专家标记的伪迹 trial。比较预先固定参数的 CSP+LDA 与 CSP+线性 SVM；分别进行按 run 留一的会话内评估、同一受试者的 T→E 跨会话评估，以及留一受试者（LOSO）跨被试评估。主指标为逐受试者 balanced accuracy，并保存所有划分、预测和数据源哈希。

**结果：**理论上 2592 个左右手 trial 中，246 个因专家伪迹标记被排除，保留 2346 个。九人等权平均的 LOSO balanced accuracy 为 CSP+LDA 62.76%±13.56%，CSP+线性 SVM 62.09%±13.58%；同一会话按 run 留一时分别为 78.06%±16.34% 和 78.21%±16.42%，跨会话 T→E 时分别为 76.06%±18.35% 和 75.05%±16.31%。LOSO 下 CSP+LDA 的逐人范围为 50.58%–93.63%。LDA 相对 SVM 的九人配对平均差为 0.67 个百分点，受试者级 bootstrap 95% 区间为 −0.70 至 2.32 个百分点，探索性精确符号翻转检验 $p=0.547$。事后保留全部伪迹标记 trial 的敏感性分析中，LOSO 平均 BA 分别为 61.50% 与 60.57%。

**结论：**在本数据集的离线左右手二分类中，固定 CSP 基线的跨被试表现低于其会话内和跨会话描述性结果，并呈现明显的逐人差异。两种线性分类器之间未观察到稳定的优势。本研究为后续空频特征与深度学习比较建立了可审计参照，但没有证明某种方法已提高跨被试泛化。

**关键词：**运动想象；脑电；共空间模式；跨被试泛化；留一受试者；可复现研究

## 1 引言

运动想象脑机接口尝试从不伴随实际运动的感觉运动脑活动中识别用户意图。脑电价格相对可及、时间分辨率高，但信号弱且会受到非脑源伪迹影响。对于应用场景，尤其重要的问题并非模型能否记住某一名受试者的模式，而是在没有该受试者校准数据时是否仍能维持可用解码。数据集、受试者和实验协议的差异会改变算法排名，因而评估过程本身需要标准化与完整报告[5]。

共空间模式（common spatial patterns，CSP）是运动想象二分类中的经典空间特征方法。它利用两类 EEG 的协方差差异，寻找使一类投影方差较大而另一类较小的通道线性组合[2,3]。滤波器组 CSP（FBCSP）进一步把频带选择与 CSP 结合，说明频谱设置也是运动想象解码的重要组成部分[4]。EEGNet 等深度模型提供了另一条方法路线[6]，但复杂模型并不能替代清楚的任务定义、受试者级隔离与传统基线。

本研究的目标是先回答一个更基本的问题：在固定预处理、固定模型参数和一致的逐试次指标下，CSP 基线从同一会话测试迁移到不同日期、再到未见受试者时表现如何？本研究不是新的域适应方法，也不以结果高于原比赛成绩为目标。贡献是：①在真实 BNCI2014_001 数据上建立可重跑的左右手二分类流程；②同时呈现三种不同外层测试单位，尤其严格的九折 LOSO；③保留逐人结果、原始试次排除数量、每折划分与逐试次预测，使读者能独立复算主要结论。

## 2 数据与方法

### 2.1 数据集与研究对象

BNCI2014_001 是 BCI Competition IV Dataset 2a 的公开版本[1]。官方实验纳入 9 名受试者，每人有两个不同日期的会话；每会话包含 6 个 run，每 run 有 48 个 trial，四类运动想象各 12 个。采集使用 22 个 EEG 与 3 个 EOG 通道，采样率为 250 Hz；采集时已进行 0.5–100 Hz 带通和 50 Hz 陷波。EOG 仅用于伪迹观察或处理，不进入分类器。原始竞赛的四分类连续因果评估与本文离线二分类逐试次评估不同，成绩不可直接比较[1]。

本文仅保留左手（标签 1）和右手（标签 2），故理论上每会话有 144 个二分类 trial，9 人两会话共 2592 个。实际可用数量以专家伪迹标记和真实读取审计为准。MOABB 的 MAT 加载器将标签化的刺激标记置于 trial 起点；实验流程中视觉 cue 在 trial 开始 2 s 后出现。原始 GDF 事件码的 cue onset 与 MOABB MAT 刺激通道的时间锚点不可混为一谈。我们逐 run 核对标签计数并按已知 2 s 偏移构造运动想象时间窗。源 MAT 文件、软件版本及 SHA-256 摘要均保留于实验记录。

### 2.2 预处理与片段提取

每个 run 独立进行固定的 8–30 Hz 四阶 Butterworth IIR 双向零相位滤波；不进行新的重参考或重采样。此滤波是分析阶段额外施加的，而不是把采集时的 0.5–100 Hz 滤波误记为我们自己的操作。双向滤波使用未来采样点，因而本文结论只适用于离线解码。

从 MOABB MAT 的 trial 起点起取 $[2.5, 5.5)$ s，即视觉 cue 后 $[0.5, 3.5)$ s。在 250 Hz 下每个保留 epoch 为 22 通道 × 750 时间点；不做基线校正。MOABB 的 `artifact_handling` 显式设为 `annotate_bad`，并以 `reject_by_annotation=True` 删除与专家伪迹标记重叠的左右手 epoch。每个 run 分别记录原始左右手数量、排除数及保留数。目标受试者的专家标记用于离线质量控制，而非类别判别；这一额外信息未必在真实无校准部署中可用，属于研究限制。

### 2.3 CSP 特征与分类器

令 $\Sigma_L$ 与 $\Sigma_R$ 为训练 trial 中左手、右手的类协方差矩阵。CSP 寻找空间权重 $w$，使两类投影方差比例不同，可写为广义特征值问题

$$
\Sigma_L w = \lambda(\Sigma_L + \Sigma_R)w.
$$

直观地说，$w$ 把 22 个 EEG 通道加权合成为一个新的“虚拟通道”；两类中能量差异明显的虚拟通道更有助于区分左右手[2,3]。本研究预先固定提取 4 个 CSP 成分，使用对数平均功率特征，并在训练折内部拟合 `StandardScaler`。随后分别训练线性判别分析（LDA）与线性核支持向量机（SVM，$C=1$）。所有步骤放在同一个机器学习 `Pipeline` 中；CSP、标准化和分类器均只对该折训练 trial 执行 `fit`。本次不搜索频带、通道、CSP 成分数或分类器超参数，避免用外层测试结果进行隐性调参。这也意味着固定选择可能不是各受试者的最优配置。

### 2.4 三种评估与防泄漏

1. **会话内（within-session）：**对每个 subject×session 单独按 6 个 run 留一验证。每折用其中 5 个 run 训练，完整剩余 run 测试。两次会话的折外预测再按受试者汇总。
2. **跨会话（cross-session）：**对每名受试者仅以其 `0train` 会话训练，以不同日期的 `1test` 会话测试。`T/E` 是原始文件历史命名，不作为其他评估的全局训练/测试标签。
3. **跨被试（cross-subject）：**九折 LOSO；每轮将一整名受试者的两个会话全部留作测试，其他八人的两个会话作为训练。目标受试者的任何 EEG epoch 都不参与 CSP、标准化或分类器参数拟合。模型不使用目标人标签进行适应。

不同情境的训练数据规模与分布同时改变，因此情境间性能差异只描述相应部署条件下的表现，不能单独归因于“受试者分布偏移”。实际 train/test 试次 ID 与归属保存在 `split_manifest.csv` 中，并由独立脚本核查无交集。

### 2.5 指标与统计单位

主要指标为 balanced accuracy（BA），即左右手两类召回率的平均：

$$
\mathrm{BA}=\tfrac{1}{2}(\mathrm{Recall}_{left}+\mathrm{Recall}_{right}).
$$

同时记录 accuracy、macro-F1、Cohen's $\kappa$ 和混淆矩阵。对 LOSO，每名被试在两次会话上合并其 trial 的预测，先计算该人的 BA，再对 9 名被试等权计算均值、样本标准差、中位数和范围；另外保留两次会话的结果。若比较 CSP+LDA 与 CSP+SVM，在同一 9 名受试者上的 BA 作配对差值，并报告基于受试者重抽样的百分位 bootstrap 区间及 $2^9$ 种符号翻转的双侧精确检验。该小样本推断为探索性描述；trial、run、session 和 9 个 LOSO 折都不能冒充独立的额外被试。

## 3 结果

### 3.1 数据审计与试次纳入

9 名受试者、2 个 session、每 session 6 个 run，共有 108 个 run。每个 run 实际检出左手 12、右手 12、双脚 12 和舌部 12 个标签事件，与官方设计一致。左右手合计理论 trial 数为 2592；排除与专家伪迹标记重叠的 246 个（9.49%）后，保留 2346 个，其中左手 1165 个、右手 1181 个。排除数在受试者间差别明显：A01 为 9 个，A06 为 67 个，不能用统一比例替代逐人审计。每个保留 epoch 的形状均为 22×750。数据来源为 18 个 MAT 文件；源文件大小与 SHA-256 均已核验。完整的逐 run 纳入表在 `outputs/P2-E001/data_audit.csv`，独立核验报告在 `outputs/P2-E001/validation_report.json`。

### 3.2 三种评估情境的总体表现

按 run 留一产生 108 个外层折，T→E 跨会话产生 9 折，LOSO 产生 9 折；两个模型合计 252 次拟合。下表每个均值与标准差都以 9 名受试者为统计单位。会话内 BA 是该受试者两个 session 的所有留出 run 预测合并后计算，而不是对折分数直接求平均。不同情境训练集规模和测试分布同时变化，不能把均值差单独解释为一个因素的因果效应。

| 评估情境 | 模型 | 9 人平均 BA | 样本标准差 | 中位数 | 范围 |
|---|---|---:|---:|---:|---:|
| 会话内：留一 run | CSP+LDA | 78.06% | 16.34 个百分点 | 85.35% | 53.60%–97.80% |
| 会话内：留一 run | CSP+线性 SVM | 78.21% | 16.42 个百分点 | 85.37% | 52.88%–96.99% |
| 跨会话：T→E | CSP+LDA | 76.06% | 18.35 个百分点 | 76.62% | 51.41%–97.79% |
| 跨会话：T→E | CSP+线性 SVM | 75.05% | 16.31 个百分点 | 78.03% | 52.82%–97.75% |
| 跨被试：LOSO | CSP+LDA | 62.76% | 13.56 个百分点 | 58.93% | 50.58%–93.63% |
| 跨被试：LOSO | CSP+线性 SVM | 62.09% | 13.58 个百分点 | 54.64% | 52.09%–93.62% |

### 3.3 留一被试结果与模型配对比较

LOSO 的最终测试单位是完整受试者，两次 session 的预测先合并，再计算该受试者的 BA。A02 的 CSP+LDA BA 为 50.58%，接近二分类的 50% 机会基线；A08 为 93.63%。这表示平均值掩盖了强烈异质性，而不是说明 A08 的信号具有已证实的特定神经机制。下表逐人列出主指标和测试试次数。

| 留出受试者 | 有效测试 trial 数 | CSP+LDA BA | CSP+线性 SVM BA | 注释 |
|---|---:|---:|---:|---|
| A01 | 279 | 53.60% | 53.60% | 近机会水平 |
| A02 | 278 | 50.58% | 52.09% | 两模型均近机会水平 |
| A03 | 274 | 72.10% | 72.10% | 两次 session 的 BA 差异较大 |
| A04 | 245 | 62.44% | 61.01% | 排除伪迹 trial 较多 |
| A05 | 264 | 52.17% | 54.64% | 两模型均近机会水平 |
| A06 | 221 | 55.05% | 54.59% | 伪迹排除 67 个，样本最少 |
| A07 | 273 | 58.93% | 52.60% | LDA 较高，但不代表总体显著优势 |
| A08 | 266 | 93.63% | 93.62% | 两模型均较高 |
| A09 | 246 | 66.35% | 64.53% | 两次 session 表现不同 |

同一 9 名受试者的 LDA 减 SVM 配对平均 BA 差为 0.67 个百分点。以受试者为单位进行 10,000 次 bootstrap 重抽样，百分位 95% 区间为 −0.70 至 2.32 个百分点；枚举 $2^9=512$ 个符号翻转得到双侧 $p=0.547$。区间跨零且样本量仅 9，不能据此认定任一分类器有可靠优势。该检验未用于选择模型或调参。

### 3.4 错误分析与图示

在全部 LOSO 测试 trial 合并的 CSP+LDA 混淆矩阵中，真实左手 1165 个 trial 里正确识别 900 个、误判为右手 265 个；真实右手 1181 个 trial 里正确识别 575 个、误判为左手 606 个。该汇总显示右手召回较低，但汇总矩阵受个体预测偏向影响，不能代替逐人 BA。例如 A01 有 95.7% 的 trial 被预测为左手，而 A06 仅有 5.0% 被预测为左手；这提示决策边界在不同目标人之间的校准可能不稳定，具体机制尚未验证。CSP+线性 SVM 的相应矩阵为 $[[975,190],[697,484]]$（行是真实左/右，列是预测左/右）。逐人 BA 图和完整预测表见实验输出。

会话异质性也并非只在模型训练情境发生。以 LOSO 的 LDA 为例，A03 的两个 session BA 分别为 58.09% 和 85.68%，A09 分别为 76.58% 和 57.69%。这些是同一受试者内部的描述性差异；本文没有测量导致差异的电极阻抗、注意状态或其他潜在因素，因此不作因果解释。

### 3.5 事后伪迹处理敏感性分析

主分析排除了与专家伪迹标记重叠的 246 个左右手 trial。为评估结论对该决定的敏感性，我们在主分析完成后，保持其余设置不变，只把这些 trial 纳入训练和测试，重新运行九折 LOSO；这是一项事后分析，不作为预先固定的主结果，也不进行新的模型选择。每位留出受试者均有 288 个测试 trial，合计 2592 个。全部源文件哈希、试次 ID、训练测试隔离和预测计数再次通过独立核验。

保留全部 trial 后，CSP+LDA 的九人等权平均 BA 为 61.50%（样本标准差 13.25 个百分点），CSP+线性 SVM 为 60.57%（13.18 个百分点）；相对主分析分别低 1.26 和 1.52 个百分点。逐人变化不一致：例如 A02 的 LDA 从 50.58% 变为 52.78%，A08 从 93.63% 变为 92.36%。此对照同时改变训练和测试样本组成，不能把分数变化解释为伪迹本身对某一侧的因果影响；它只说明主结论的总体量级对该离线质量控制规则不完全依赖。完整逐人结果在 `outputs/P2-E002-ALLTRIALS/subject_metrics.csv`。

## 4 讨论

本研究的关键观察是：固定的 8–30 Hz CSP 特征配合两种线性分类器，在同一受试者内部平均可达到约 75%–78% 的 BA，但面对完整未见受试者时，平均 BA 为约 62%；同时，LOSO 最弱受试者接近机会水平，最强受试者高于 93%。这种强烈的逐人异质性意味着只汇报平均准确率会掩盖实际部署风险。它与“不同人 EEG 分布可能不同”的研究动机相容，但本研究未直接估计分布距离，也未隔离训练集大小等因素，不能将性能差全部归因于神经生理差异。

跨会话 T→E 的均值介于会话内和跨被试之间，但 A03、A09 的两 session 变化提示“同一人”也并不自动保证稳定。与此同时，跨会话训练仅使用一个 session，LOSO 却用八人的两次 session；三种协议的样本量、测试对象和时间关系均不相同，因此本文将它们视作不同部署问题，而非一个受控单因素试验。

LDA 与线性 SVM 在 LOSO 上的平均差不到 1 个百分点，配对区间跨零。在该固定 CSP 特征与样本规模下，没有证据表明更换这两种线性分类器能系统改善未见受试者表现。混淆矩阵和逐人预测比例进一步提示部分留出受试者出现明显类别偏向；下一步研究可预先注册空间/频谱特征稳健性实验、训练人群内的参数选择及适应方法，并检查这种偏向是否可重复。不能根据本次结果声称已经“提高”跨被试泛化，也不能由离线 BA 推断实时脑机接口可用性。

## 5 局限与后续研究

第一，只有一个公开数据集和 9 名受试者，对不同设备、任务与群体的外推有限；受试者级统计检验的功效也有限。第二，本研究仅是左右手二分类，不能与原始四分类比赛结果直接比较。第三，固定 8–30 Hz 和 4 个 CSP 成分控制了选择偏差，却可能忽略受试者差异；下一阶段应在训练受试者内部嵌套选择频带和空间成分，再严格验证 LOSO。第四，专家伪迹标记及零相位滤波使本研究属于离线清洁 trial 条件，不等同实时无监督部署。第五，EEGNet、Filter Bank CSP 和域适应仍是计划中的比较方法，不属于本文实测结论。

## 6 结论

在 BNCI2014_001 的离线左右手运动想象任务中，固定 CSP+LDA 与 CSP+线性 SVM 的九人等权 LOSO 平均 balanced accuracy 分别为 62.76% 和 62.09%。逐人结果从近机会水平到 93% 以上，说明该传统基线的跨被试泛化高度不均；两种线性分类器之间未见稳定差异。结果为后续可复现的空频特征消融和 EEGNet 比较提供了参照，但尚未构成泛化改进方法或可投稿的完整创新结论。

## 数据、代码与可复现性声明

分析使用公开 BNCI2014_001 的 MOABB MAT 镜像，脚本、冻结参数、环境锁文件、源文件哈希、逐折划分、逐 trial 预测与汇总表位于同一项目。按照数据集许可和要求引用原始说明及相关论文；大体积原始 EEG 文件不应直接提交 GitHub。可使用项目根目录中的命令重跑：

```powershell
uv sync --locked --python 3.12 --extra dev
.\.venv\Scripts\python.exe scripts\run_csp_baselines.py --output-dir outputs\P2-E001-replication
.\.venv\Scripts\python.exe scripts\validate_csp_run.py outputs\P2-E001-replication
```

需要保持与当前实验相同的依赖锁、输入文件哈希和预处理参数。随机种子已固定，但该版本的两个分类器与数据划分基本是确定性的；不同计算环境出现微小数值差异时，应检查 BLAS、MNE 与 scikit-learn 版本。

# 从傅里叶变换到四分类滤波器组：本项目的信号处理说明

更新：2026-09-23。配套配置 `configs/q4_e001_fourclass_filterbank.json` 与运行 `outputs/Q4-E001/`。这是方法教学，不预言实验结果。

## 问题

运动想象时，感觉运动皮层附近的 μ（大致 8–13 Hz）和 β（大致 13–30 Hz）节律可能随任务改变。若把 4–40 Hz 当成一个宽频信号，空间滤波器只能基于宽频总协方差寻找差异；不同频率的模式可能互相抵消。我们的假说是：分别对窄频带学习空间滤波器，再组合特征，可能更容易迁移到新的受试者；也可能因为特征过多而过拟合。

## 傅里叶变换做了什么

一个 EEG 通道是按时间采样的序列 $x[n]$。离散傅里叶变换把它拆成不同频率的复数系数：

$$X[k]=\sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}.$$

在 250 Hz 下，任意可解释的频率不能超过 125 Hz（Nyquist 频率）。用 $|X[k]|^2$ 可以描述频率功率，但短段 EEG 的一次直接平方会很不稳定。P3 使用 Welch 方法：对每条试次的短时间窗加 Hann 窗、让窗之间重叠、分别计算功率谱密度（PSD）后取均值，再按 8–12、12–16、16–20、20–30 Hz 积分。P3 的 88 维来自 22 通道 × 4 频段；这个步骤**不是**脑源定位，也不能从普通 PSD 曲线直接读出运动想象 ERD。

Q4 的滤波器组不是把傅里叶系数直接送进模型，而是用固定带通滤波器把每条连续 run 的信号分为 4–8、8–12、…、36–40 Hz 九条带。带通滤波可以理解为“保留一段频率、抑制其余频率”，但真实滤波器有过渡带，靠近 8/12/… Hz 的成分不会被理想地截断。每个频带的滤波是固定四阶 Butterworth，不通过类别标签学习系数；所有 run 使用相同配置。

## 频率与空间如何结合

每个频带有一个 $22\times22$ 的通道协方差矩阵，元素描述两个通道活动如何共同变化。CSP 寻找一组加权通道 $w$，使投影 $z(t)=w^\top x(t)$ 的方差对类别有辨别力。二分类可用广义特征值问题直观理解：

$$\Sigma_1w=\lambda(\Sigma_1+\Sigma_2)w.$$

当 $\lambda$ 接近 1 或 0 时，投影分别偏向一类。完整四分类没有这一个简单的两矩阵比值；Q4 使用 MNE 多类 CSP 的联合对角化实现，每频带取 8 个 log-power 空间特征。九条带合并为 72 维；宽频 4–40 Hz 对照为 8 维。随后用训练被试的特征拟合标准化、LDA 或线性 SVM。另有源训练互信息选择 8/72 特征的敏感性分析，用来观察维数影响；它不是对“相同模型容量”的严格控制。

## 研究设计为何如此安排

BNCI2014_001 每人两会话、四类各 144 个试次，总共九人 5184 个 trial。外层 LOSO 每次把一整人的 576 个试次（两会话）留下，其余八人的 4608 个 trial 用于 CSP、互信息选特征、标准化和分类器拟合。所有模型预测相同的目标试次，才能把差异归因于表示与分类方法，而不混入测试集组成变化。评价先在每名目标受试者上算四类 balanced accuracy，再九人等权汇总；四类完全均衡时，全试次 BA 与 accuracy 数值相同，但语义仍须写清。

**注意伪迹**：4–40 Hz 会排除 50 Hz 工频主峰，所以此协议没有额外 50 Hz notch；但眨眼、肌电、坏导电极的频谱并不只在 50 Hz，也可能进入 μ/β 频段。更陡的滤波或更多去噪不自动意味着更好的跨人解码。Q4 主分析包含所有专家标记试次；另记录被标记/未标记测试试次的分层表现。目标测试者的标记仅用于**事后分析**，不用于训练或主结果的选择。

**注意时间因果性**：零相位滤波在离线处理一个 run 时可使用事件之后的信号。因此结果表示离线条件，不能直接作为实时 BCI 系统的延迟/因果性能。若后续目标转向在线部署，需另设计因果滤波和时间边界控制。

## 如何解释即将得到的数字

如果滤波器组平均分数更高，还要检查是否由少数受试者驱动、是否有个体下降、被标记试次是否更脆弱、72 维相比 8 维是否仅因容量变大。若差异很小或反向，属于有价值的负结果，不能临时改窗长或频带后仍把新结果称为预定对照。P3 的二分类 CSP+Welch PSD 融合曾得到描述性 +1.78 个百分点，但其区间跨零。[2023 年 CSP+PSD 联合特征](https://www.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2023.1175399/full)和[2025 年 STFT 跨人二分类](https://arxiv.org/pdf/2507.02510)已有直接先例。因此真正需要回答的是在严格跨人协议下，哪类信息能稳定帮助多数新受试者。

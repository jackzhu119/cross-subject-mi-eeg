# Data policy

本目录只保存数据说明，不把大体积 EEG 文件提交到版本库。

建议逻辑分层：

```text
data/raw/        下载后的原始文件或只读缓存映射；永不覆盖
data/interim/    可重建的临时结果，例如经过固定滤波的 Raw/Epochs
data/processed/  明确版本和参数的建模输入
```

规则：

1. `raw` 只读；任何清洗都生成新对象或新文件。
2. 不把 Subject 9 之类的测试受试者用于拟合归一化、CSP 或选择频带。
3. 每个样本保留 dataset、subject、session、run、trial 和 label。
4. 每次处理记录输入文件、代码版本、参数、输出路径和样本计数。
5. BNCI2014_001 的 EOG 通道用于伪迹检查/校正，不作为分类特征。

MOABB 默认可能把数据放到用户级 MNE 数据目录，而不是本目录。首次下载前应记录实际缓存路径；不要复制出多个来源不明的数据版本。

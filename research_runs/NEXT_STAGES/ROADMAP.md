# Q11–Q14 research roadmap and immutable planning matrix

Date: 2026-09-24. Parent repository commit: `c6c347edd763108ab867d4ae0b191cb6d00c361c`. This is a **post-Q9 plan**, not a claim that any Q11–Q14 experiment has run, that its code has been implemented, or that the plan is a preregistration. `MATRIX.json` is the machine-readable source of proposed condition IDs and new-fit arithmetic. The new Q10 spatial-projection and geometry experiments have separate owners; this directory does not alter their code or outcomes. Q5–Q9 remain immutable comparators.

## Scientific question and decision hierarchy

The paper-level question is whether **source-derived spatial and spectral representations** improve *zero-calibration* cross-subject motor-imagery decoding, and whether any effect survives duration, model-capacity, source-composition, session and independent-cohort controls. The primary BNCI2014_001 task remains four-class left hand, right hand, feet and tongue. Every new BNCI result is exploratory because Q5–Q9 target scores have already been examined. A first frozen evaluation on an appropriate external cohort is needed before stronger claims about generalization.

1. **Validation gate (G0).** Independently recompute Q9 prediction metrics, all 9×3 subject/seed coverage, class-wise recall and collapse, exact trial IDs, source/validation/target disjointness, selected epochs from four source-only curves, transform fit lists and hashes, and checkpoint/probability checks. `results/Q9-BATCH/validation_report.json` says `passed_orchestration_only` and explicitly says scientific validation was not performed. A failed gate blocks *claims* and publication; do not repair Q9 files in place.
2. **Representation and architecture (Q11).** Separate band decomposition from shared/independent fusion, early versus late fusion, parameter count, conventional spatial methods and non-EEGNet CNNs. The fixed four-band set and each architecture must be finalized in code/config before inference. Never select the apparent winner from outer target performance and present it as a prespecified BNCI result.
3. **Source-only robustness (Q12).** Evaluate a frozen source-pooled whitener and source-subject GroupDRO against the unmodified frozen comparator; separately test channel dropout and gain augmentation only in source training. Original Euclidean Alignment often estimates target-subject covariance despite requiring no target labels: it belongs to a different, explicitly *transductive* experiment and is excluded here.
4. **Selection and heterogeneity (Q13).** Test duration robustness without altering Q8/Q9, source-count and balanced source-subset effects, and source-session dependence. Source-size experiments reuse each method's already frozen all-source LOSO epoch to isolate training-set composition; this is a conditional source-size study, not a new few-source selection algorithm. The k=8 row is the frozen Q8/Q9 comparator, not a redundant retraining.
5. **Independent cohort (Q14).** Use a *new binary task* matching left/right hand imagery across datasets. PhysioNet runs 4/8/12 are left/right **imagery**; execution and bilateral hands/feet runs are out of scope. PhysioNet has no BNCI tongue label. Before any external classifier output, audit original files/events/electrodes/windows/reference/units and freeze an ordered common channel set, a common cue-relative window and sampling method, a per-subject eligibility rule, and all binary models/seed/selection rules. Q14-E001 reruns BNCI on this harmonized binary protocol, Q14-E002 tests one BNCI-trained model zero-shot on all eligible PhysioNet people, and Q14-E003 uses PhysioNet-only source-subject LOSO. These are separate claims and tables.

## Fit counts, not compute promises

For one new BNCI neural condition with the Q8/Q9 nested protocol, `9 outer targets × 4 inner source-subject folds × 1 selection seed = 36 inner fits` plus `9 targets × 3 final seeds = 27 final fits`, hence **63**. Existing Q8/Q9 comparator fits are reused, not counted as new fits. A shallow pipeline with fully fixed parameters has 9 outer-source fits. If source-only tuning is added, its additional inner fits must be declared in a new matrix version **before** target inference.

`N=109` is the official dataset's maximum subject count, **not** an eligibility result. The external metadata audit may change it, in which case replace `14N` and `N` rather than silently deleting people. Q13's 54 frozen k=8 final fits are reference observations, not new fits. Planned fit count is not an ETA: Q9 throughput does not directly apply to 109-person, 64-channel external training. Measure each new condition's real preprocessing, fit speed, RAM and disk use before queueing it on a paid host.

## Source-only and data-identity assertions

- Each outer target contains **both** sessions, all target trials and all four labels. Inner fitting excludes both outer target and its own two inner-validation source subjects. Keep Q8/Q9 22-channel order, 250 Hz, trial-start `[2.5,5.5)` seconds, Q8 run-local 4–40 Hz filtering for broadband controls, fixed volts-to-µV conversion and all-trial primary population unless an explicitly named condition changes *only* its declared representation/training rule.
- A deterministic PSD or covariance of an individual unseen trial is a model input and is allowed. Pooling target trials to estimate an alignment matrix, tangent reference, feature scaler, class prior or normalization statistic is **not** allowed. For pyRiemann tangent-space pipelines set `tsupdate=False`; fit reference, CSP/PCA, scaler and classifier on the exact source-training partition and save its subject/trial IDs and checksum.
- Inner curves for new neural representations are separately trained and selected using the earliest epoch minimizing equal-inner-fold mean of *within-fold rank* of validation cross-entropy over epochs 1–40, selection seed `20260923`. Final seeds are `20260924/25/26`. Fixed-duration and reused-curve Q13 controls are explicitly marked as sensitivities and must never replace the frozen Q8/Q9 results.
- Save exact `dataset/subject/session/run/trial/event/label` identities and compare the same target trial inventory across conditions. Store full 4-vector predicted probabilities, confusion matrices, source fit manifests, selected epochs, learning curves, code/config/MAT hashes, dependency/GPU manifest, checkpoint hashes, stdout/stderr and failures. Atomic per-fit completion receipts must be validated before resume skips a fit.
- No target-based condition stopping, seed selection, preprocessing revision, subject exclusion or partial-positive-results promotion. A technical failure may stop the queue at an ID boundary; its status stays `failed`/`not_started`, never `negative`. All null and worsened-subject results remain in aggregation.

## Statistics and figures to predeclare

The primary descriptive unit is the **held-out subject**. Compute each subject's BA mean over the three *paired* seeds, then the equal-subject mean and sample SD. For each planned contrast save all nine subject differences, mean, median, minimum, maximum, class-wise recalls, macro-F1, κ, aggregate and per-subject confusion matrices, seed SD and session-specific BA. Bootstrap subjects, not trials or seed rows, for an exploratory interval; show an exact nine-sign-flip sensitivity only with the caveat that highly overlapping LOSO training sets limit a strict randomization interpretation. Report leave-one-target-out influence, especially whether changes are driven by S3/S8 or any other one person. Predefine contrast families (`spectral_fusion_capacity`, `architecture`, `classical_filter_bank`, `source_only_domain_generalization`, `source_only_augmentation`, `epoch_selection_sensitivity`, `source_subject_quantity_and_composition`, `source_session_robustness`) and if p-values are shown, give unadjusted and Holm-adjusted values *within family*; do not pool unrelated post hoc contrasts into a fictitious confirmatory family.

For Q13 source-count, first average four predetermined subsets **within each target and source count**; 117 target/subset cells and three seeds are not 117 independent people. Plot paired subject trajectories at k=2/4/6/8, effect of source composition within each k, and the frozen k=8 endpoint. For Q13 session controls, report target session T/E separately using the same final models. For artifact flags, stratify *after* all-trial inference and display class counts: an expert flag is not proof that a classifier has removed interference.

Publish a deterministic analysis inventory: per-subject/seed tables; per-class recall and predicted-class dominance; subject-paired effect forest plots; session/flag strata; learning-curve/epoch-selection plots; source-count trajectories; spectral-filter or covariance descriptors where interpretable; and complete coverage/failure tables. A changed mean BA alone is not evidence of neural mechanism. Fixed offline zero-phase filters are not causal online filters; no deployment claim follows.

## External validation boundary

The metadata-only Q14-V001 gate should use official PhysioNet annotation semantics: runs 4/8/12 are left/right hand imagery; `T1` and `T2` in those runs have that meaning, while the same event codes in other runs do not. PhysioNet's documented full dataset size is 3.4 GB, but downloading only required runs is preferable. Resolve actual common electrodes rather than inventing an intersection count. Use an ordered intersection, fixed reference policy, anti-aliased resampling and a cue-relative window supported by **every** included event; freeze these before any external scores. Do not allow external target aggregate statistics, source+target normalization, model selection on PhysioNet results, or target-person calibration in Q14-E002. Select final models using BNCI source-subject-only folds, train on all nine BNCI people, and infer once on each eligible PhysioNet person. Within-Physio LOSO must use only other PhysioNet people for fitting/selection, with 4 deterministic source-subject inner folds; compare methods on the *same* external target trials. External binary BA has 0.50 chance level, not BNCI four-class 0.25, and cannot directly validate four-class tongue decoding.

A second independent cohort may be planned after Q14 is frozen: Cho2017 offers 52 left/right imagery people but requires separate metadata/storage review and its own experiment ID. Lee2019_MI offers 54 people and two sessions, again with a distinct data contract. **Do not** use the MOABB `Schirrmeister2017` high-gamma dataset as four-class motor *imagery* confirmation: its four classes are executed movements/rest and do not include tongue.

## Execution and publishing contract

`MATRIX.json` deliberately has only `planned_unimplemented` or `blocked_*` statuses. It is **not** an executable queue. Converting a condition to runnable requires separately reviewed and tested config, runner, validator, resume logic and receipt schema, then a versioned commit before new target predictions. A later activation manifest should record planned/runnable/blocked/complete states separately; do not mutate this frozen planning artifact to claim execution. Run one GPU training job at a time on the current host, preserve checkpoint/curve/failed-attempt artifacts, and push only reviewed source/result/provenance files to GitHub. Never upload raw EEG files, credentials or SSH keys. An automated publisher may push only after all selected jobs pass both orchestration **and independent scientific** validation; errors remain visible and must not be converted into a green completion receipt.

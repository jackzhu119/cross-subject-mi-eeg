# 英文论文稿中文说明

日期：2026 年 10 月 2 日。当前交付为作者审阅稿，采用通用期刊结构。

论文题目：**Source-only model selection and shared spectral representations in cross-subject motor-imagery EEG decoding**。

建议中文题目：**跨受试者运动想象脑电解码中的源数据模型选择与共享频谱表征**。

## 这篇稿件写了什么

本稿依据 GitHub 与仓库内已完成的科研实验，整合四分类内部研究、模型选择诊断、频谱与空间对照、鲁棒性实验、训练时长及来源组成控制，以及独立人群的二分类外部评估。Q15、Cho2017、Lee2019_MI 的未来训练结果不进入本稿。

论文主线是训练时长选择如何影响跨受试者泛化，以及共享 mu/beta 频段模型的效果能否得到支持。它适合定位为完整报告正、负结果和受试者差异的探索性研究；现有证据不支持将其写成已证明普遍优越的新模型。

本次核对了 GitHub main 的 `adb2d406b4300e2c8e4d5112969291c0331f3ed5`，并读取对应仓库中的配置、结果、预测、统计和验证记录。“科研”项目已定位，但聊天历史接口在限定时间内未响应，因此没有声称读取到其历史对话。较早的进度文档对 Q13 的状态已过时，本稿依据后续完成的真实结果。

## 可以支持的主要结果

| 问题 | 已完成结果 | 论文应采用的解释 |
| --- | --- | --- |
| 源数据训练时长选择 | 九人四分类中，平均验证损失选择为 33.72% BA；平均排名选择为 42.67% | 增益集中于 S3、S8，内部分析受既往同一数据集探索影响；不能声称独立确认或普遍有效 |
| 训练时长与归一化 | S3 原始处理输入从 2 到 16 epochs，BA 从 26.10% 到 67.71%；2 epochs 的源归一化为 25.69% | 单人诊断支持检查训练时长，不能外推为所有人的失效机制 |
| 同运行环境时长控制 | 固定 20 epochs 相对历史所选时长平均高 10.06 个百分点，95% bootstrap 区间约 [+0.68,+21.53]；精确 sign-flip p=0.125 | 方向保留，但九人统计证据依赖检验方法；不是普遍最优时长的证明 |
| 四分类共享频谱 | 共享 mu/beta 为 42.19%，宽频排名基线为 42.67%；差值 −0.48 个百分点，归档区间 [−3.21,+1.41] | 未确立共享频谱优势 |
| 源数据鲁棒性 | 六项介入均未确立经过既定多重校正的增益；GroupDRO 相对匹配 balanced ERM 的点估计更低 | 报告负结果；与旧 Q8 基线的比较还跨运行环境 |
| 独立人群外部评估 | PhysioNet 109 人二分类：宽频 61.81%、共享 62.39%、CSP+LDA 54.46%；共享减宽频 +0.573 个百分点，95% 区间 [−0.097,+1.242]，p=0.06446 | 平均差值小且不确定，未确立外部优势；CSP 是背景对照，不替代预定主比较 |

BA 指 balanced accuracy，即各类别召回率的平均值。四分类机会水平为 25%，二分类为 50%。种子先在每个人内平均，再按人平均；三次种子运行不是三个独立受试者。上述区间以人为重采样单位，各实验的抽样次数和 seed 在英文 Methods 中分别注明。

## 已在文中处理的关键边界

内部 BNCI 四分类使用九人、两次 session、5,184 条试次，主要评价保留 488 条专家标记的伪迹试次。每个目标受试者的两次 session 均排除在训练和选择之外。早期 P2/P3/P4 的二分类、干净目标试次、同人校准及 EOG 条件另放补充材料，不能与四分类主分析混算。

外部评估为 4,918 个独立试次、327 个官方校验过的 EDF；34,426 条保存预测来自每试次七个模型/种子输出，不是同等数量的独立样本。S88、S92、S100 的实际采样率是 128 Hz，部分外部运行停止后按元数据修订为确定性重采样。87 人旧输出保持原字节，另完成 22 人。该修订没有使用目标成绩选参数，但仍需披露发生在部分外部执行之后。

保存概率重新写入 CSV 引起的精确浮点比较失败，与之后的跨主机运行环境限制分别报告。后续可移植验证核查官方文件与事件、保存概率、argmax、成绩和统计；它没有在新主机重新生成全部 checkpoint 预测。归档精确零差值规则及浮点容差敏感性也同时保留，不用另一种规则改写主结果。

实验清单含 61 条 Q4–Q14 条件记录，以及 34 条早期二分类质量检查结果。单人诊断、重复端点、失败、未运行分支和仅分析任务均注明。清单行数不代表独立实验数量或累计训练次数。

## 文件怎样使用

- `manuscript_en.pdf`：已生成的英文阅读稿，正文、补充材料、参考文献在同一文件。
- `manuscript_en.docx`：可编辑 Word 稿，适合补作者、改文字和套用目标期刊模板。
- `manuscript_en.md`：便于版本管理的英文全文。
- `manuscript.tex`：自包含 LaTeX 源文件，内嵌各图的数值绘图，不依赖外部图文件或 `.bib`。内置编辑器打开和编译请求均超时，因此尚未确认 LaTeX 编译成功。现有 PDF 由文档排版程序单独导出。
- `figures/`：四幅图各有 PNG、PDF、SVG；后两种适合投稿时保留矢量质量。
- `tables/`、`evidence/`：逐人表、完整条件清单、统计与来源哈希，便于审阅和复核。
- `supplementary_completed_experiment_inventory.md`：已完成实验及技术历史的英文清单。

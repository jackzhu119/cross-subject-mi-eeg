# Preanalysis: a new retrospective source CSP diagnostic

Prepared 13 October 2026. This protocol will be committed and publicly read back before fitting. It addresses the source-efficacy/provenance gap of the contextual Q15 CSP specification. It does not test the redesigned neural duration-selection hypotheses on an independent cohort.

Use all 18 original BNCI2014_001 MAT files, freshly obtained from the official provider and matched byte-for-byte to the frozen Q8 SHA256/size list. Include both sessions and all 2,592 binary hand trials, including provider artifact flags. Reuse the unchanged audited Q15 context implementation: select its 21 ordered channels (FCz excluded), CAR21, native 8–30-Hz fourth-order zero-phase SOS filtering per six-second trial context, polyphase resample to160Hz, cue crop[0.5,2.5) giving21×320 float32 epochs. This diagnostic differs from the planned new19-channel independent-target experiment.

The model is fixed21→20 Helmert coordinates, MNE CSP4 (reg=None, log=True, cov_est=concat, norm_trace=False, rank=full, component_order=mutual_info, average_power), source-fitted StandardScaler and LDA(svd). No hyperparameter search, data-driven regularization, epoch choice, target input, target labels, target centering or model-class selection is performed.

Run nine leave-one-source-person-out fits; each fits both sessions of the other eight people and predicts both sessions of the held-out person. Run one additional all-nine-source fit and score its own training data as explicitly labelled resubstitution. Exactly10 new source fits are planned; these must be counted as additional fits, not appended to or confused with the original Q15 total15. No new neural fits or target predictions are authorized by this protocol. The old frozen model is not configured for deserialization/replay because its matching original runtime is not established.

Save every fit partition and trial ID, real fit receipt/counter, raw/epoch/label/source code/runtime digests, model weights, original probabilities and predicted labels. Actual float64 Pipeline inputs must be hashed, with the original float32 epoch provenance recorded separately. Independent validation rereads native trial labels/flags from original MAT files and recomputes every person confusion matrix and BA from saved predictions without executing a model.

Report all nine scores, signed class-recall asymmetries, left-prediction frequencies, mean/person SD and the training resubstitution score. No confirmatory p-value, clinical failure threshold, causal device mechanism or intrinsic CSP inferiority is inferred. Known source participants have been repeatedly studied; this is retrospective diagnostic evidence, not fresh-person confirmation. If a new score rounds to an earlier report value, that coincidence does not authenticate the earlier code/partition/centering run.

A runtime or source inconsistency is an execution failure requiring a recorded amendment before another fit; negative/low results alone do not authorize changes. Completed unsuccessful runs remain public. The baseline gate, CPU configuration, executor, independent validator and imported Q15 code/contracts must be part of the preanalysis commit/public-byte verification.

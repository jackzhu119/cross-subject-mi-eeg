Protocol drafted 2026-09-24 from repository `main` at `13421ef3a5739a79f152087cafce9fccad59e5e4`. New experiment IDs are Q9-E001 through Q9-E005. Nothing in this document is a Q9 empirical result, a completed preregistration, or proof of independent validation. Q5–Q8 remain read-only. Implement and test the runner, then commit/tag its configuration and code **before any Q9 target predictions are inspected**. No result-driven changes to the matrix below are allowed; deviations require a new experiment ID and a dated rationale.

## Research question and mechanism

Can a fixed mu/beta spatial-spectral representation improve four-class, zero-calibration cross-subject MI decoding beyond the now-frozen Q8 source-only EEGNet baseline? Does any benefit come from frequency decomposition, source-fitted spatial filters, or merely training duration / artifact composition?

The scientific motivation is the signal-processing sequence: Fourier/PSD analysis identifies candidate oscillatory frequencies; a *fixed* filter bank extracts mu/beta activity without target tuning; CSP or PCA tests whether source-derived spatial projections add discriminative information; EEGNet then learns temporal/spatial patterns. The existing Q4 FBCSP results are a frozen traditional comparator, not a result to re-optimize. The Q9 bands are protocol choices, not a claim that all participants' discriminative frequencies are identical.

## Invariant data/evaluation contract

- Dataset: BNCI2014_001, subjects S1–S9, four labels 1=left hand, 2=right hand, 3=feet, 4=tongue. Both sessions of each target subject are held out; 576 trials/subject. Never use target labels, distributional moments, artifact flags, or performance for training, normalization, feature selection, duration selection, or hyperparameter choice. Target flags are used only for post-inference stratified reporting.
- Preserve Q8's 22 EEG-channel order, native 250 Hz, epoch `[2.5,5.5)` seconds from trial start, 750 samples, all trials including flagged trials for the primary population, no baseline, and fixed `1e6` volts-to-microvolts conversion. The core Q8 comparator retains its 4–40 Hz fourth-order zero-phase Butterworth preprocessing. The new Q9 fixed filter variants use the *same run-local filter design* and only the bands declared below. Do not add a 50 Hz notch to a ≤40 Hz low-passed signal as a post-hoc optimization.
- Outer split: nine source-only LOSO folds. Inner split: the same four consecutive pairs of the sorted eight source subjects as Q5/Q8. Within each inner fold, any fitted scaler, PCA/CSP, or EOG/artifact model uses only its six source-training subjects; the two inner-validation subjects are held out. For a final fit, fitted transforms use the eight outer source subjects only. Every fitted transform has a saved subject list and hash.
- Model-selection **algorithm** is frozen to Q8's earliest epoch minimizing the equal-inner-fold mean of within-fold validation-CE ranks over epochs 1–40. Recompute the four inner curves for each new representation with selection seed `20260923`; do **not** copy Q8's epoch numbers except in the explicitly labeled fixed-duration control Q9-E002. No target-based epoch or seed selection.
- Neural training controls: Braindecode EEGNet from Q8, F1=8, D=2, F2=16, temporal kernel=64, dropout=.25, batch=64, Adam learning rate=.001, weight decay=0, no scheduler/augmentation, deterministic algorithms, three final seeds `20260924/25/26`. Preserve the Q8 label mapping, loss, channel/time tensor semantics and evaluator. A changed number of input channels alters the spatial layer's parameter count and must be disclosed. Do not silently reduce the batch size or epoch cap to fit hardware; record a failed run and a new protocol if that becomes necessary.
- Primary measure: each subject's balanced accuracy averaged over the three seeds, then equal-subject mean. Report nine subject rows, subject SD, median paired change, all classes' recall, macro-F1, kappa, full confusion matrices, seed variability, and session/artifact strata. Four-class chance BA is 0.25 in the balanced target population. Never treat 27 seed fits or 15,552 trial-level predictions as independent subjects.

### Representation definitions

- `MID_8_30`, `MU_8_13`, `BETA_13_30`: one 22×750 float32 EEG tensor per trial from fixed fourth-order zero-phase Butterworth run-level filtering. Boundaries are in Hz. All bands use the same original run, events, trial IDs, and channel order. The fixed 8–13/13–30 split is **not** optimized on Q8 target results.
- `MU_BETA_SHARED`: two 22×750 tensors. A **single parameter-shared EEGNet** processes both bands in one concatenated mini-batch; reshape its output to `(trials, 2, 4)`, average the two class logits, then apply one cross-entropy loss. No learned per-band weighting, target-derived fusion weight, or duplicated independent network. This preserves EEGNet parameter count relative to Q8, though preprocessing and forward-pass cost differ. Use the same operation in inner validation and final inference.
- Q9-E003 CSP: for each band, fit the existing Q4 MNE multiclass CSP configuration (`n_components=8`, OAS covariance regularization, `cov_est=concat`, no trace normalization, full rank) on labeled *source-training* trials only; apply its first eight spatial filters as time-series projections to source validation/target. Concatenate eight mu + eight beta projected channels to shape 16×750 and train EEGNet with `n_chans=16`. Fix each filter's sign by making its largest-magnitude coefficient positive. Store filters, fit-subject IDs, signs/order and hashes. The supervised CSP procedure must be fitted anew inside each inner fold.
- Q9-E003 PCA control: per band, fit an eight-component channel covariance PCA on the same source-training trials only, with fixed centering and eigenvector sign convention; concatenate 16 projected channels. It uses no labels. Model architecture and 16-channel width match the CSP condition. **For both CSP and PCA**, fit per-projected-channel mean and SD on that partition's source-training samples only and apply the fixed values to its validation/target samples; save these values and fit-subject IDs. Neither method fits on target data.
- Q9-A001 PSD: take the Q8-filtered 4–40 Hz EEG after µV scaling. Welch: 250-sample Hamming windows, 125-sample overlap, `nfft=250`, constant detrend, density scaling, average windows. Integrate `8 ≤ f < 13` and `13 ≤ f ≤ 30` Hz bins separately (`sum(PSD) × Δf`), then fixed `log10(power + 1e-12)`; 22 channels × 2 bands = 44 features/trial. Fit StandardScaler and then shrinkage LDA (`lsqr`, auto) or linear SVM (`C=1`) on outer source subjects only. Define and test the exact SciPy version/units before the run. This is a *spectral feature baseline*, not a Fourier-based artifact-removal claim.

## Analysis locked before computation

Primary Q9-E001 contrast: paired nine-subject BA difference `MU_BETA_SHARED − Q8`, averaged across the three paired seeds per subject. Report mean and median difference, subject bootstrap 95% CI (resample nine subjects, not trials), exact sign-flip/permutation sensitivity, all nine differences, and `S3/S8-excluded` diagnostic. Do not treat a small p-value here as confirmatory because this dataset has already shaped the research program. The other Q9-E001 conditions and Q9-E003 are a declared secondary family; if inferential p-values are shown, report unadjusted and Holm-adjusted values and identify the primary contrast distinctly. Q9-E002, E004, E005 and Q9-A001 are mechanistic/robustness sensitivity analyses, not candidates from which to cherry-pick a single winner.

Report class-wise recall and prediction-distribution entropy/dominant-class share for every subject. Explicitly count cases where one or more classes have zero recall. Show S3/S8 and every worsened subject, not only the mean. Include paired confusion-matrix changes; aggregate confusion is supplementary because target heterogeneity is the focus. Flagged/unflagged target strata are secondary descriptive endpoints and may have imbalanced class counts. Sessions are reported separately without changing training.

No Q9 model is chosen by held-out target mean BA for a later confirmatory claim. To establish generalization of a chosen method, **freeze it and evaluate on an independent external cohort/dataset** with a separately audited class/epoch/channel harmonization protocol. If no suitable external dataset exists, the manuscript must explicitly remain an exploratory single-dataset study.

## Limits and paper-readiness gate

This batch is intentionally broad but hypothesis-organized, not a grid search. It cannot by itself convert same-dataset exploratory work into confirmatory external evidence. Fixed offline zero-phase filtering is non-causal and should not be described as real-time deployment. CSP/PCA feature fitting may be sensitive to source composition. The E004 source-clean condition uses expert trial flags, not a universal deployable artifact detector. All technical failures and null/negative results belong in the research log and paper supplement.

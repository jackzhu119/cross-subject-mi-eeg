# Q13-E006: matched-runtime source-only raw-CE comparator

This amendment was motivated by an environment mismatch **before** Q13 was run, not by target accuracy. Frozen Q5 raw-CE fits used PyTorch 2.14/CUDA 13.2; the most recent Q12 runtime receipt used PyTorch 2.8/CUDA 12.8. The future Q13 runtime is not known until its preflight. Reusing Q5 as the only comparator for a new Q13 fixed-20 run could mix the epoch-selection effect with runtime and device changes. The original Q5 results and the Q13-E001 matrix are preserved. Q13-E006 adds exactly **27 final fits** (9 held-out subjects × 3 frozen seeds) under the **same packages, CUDA runtime, GPU model, preprocessing, architecture, optimizer, data files and Q13 training implementation** as Q13-E001/Q8_FIXED20, changing only the epochs to the frozen Q5 source-only raw-CE schedule. No new inner fitting, model search, target fitting, or target-driven choice is permitted.

Q5 selection is recomputed from its 36 archived inner curves (four source-only folds per target, earliest minimum equal-fold mean raw CE) and checked against its selection receipt. The nine target subjects remain excluded from training; each fit evaluates both target sessions and all 576 trials. The runner refuses to start until Q13's original 837-fit scientific validation has passed, the Q8_FIXED20 arm is complete, the Q5 and Q13 code/protocol files are committed unchanged, all 18 BNCI MAT hashes match the fixed-20 arm, and Python/platform/package/CUDA/GPU receipts match. It also retrieves the seven training-code Git blobs from Q13 fixed-20's recorded historical commit and requires the current files to be byte-identical, so an intervening code commit cannot silently alter the comparator. It writes only to `results/Q13-E006` and does not alter the Q5 or Q13-E001/E004/E005 results.

This is an **exploratory sensitivity comparison on already examined BNCI targets**. It tests the *historical Q5 source-only epoch schedule* against fixed 20 under one runtime; it does **not** show that re-running the inner selection in the newer runtime would choose the same epochs. The original Q5 versus Q13 fixed-20 contrast should remain labelled cross-runtime descriptive if the runtimes differ. If Q13-E006 eventually passes its own independent prediction and checkpoint validator, E006 versus Q13-E001/Q8_FIXED20 becomes the preferred matched-runtime duration contrast, with nine subject-level paired differences and all three paired seeds; do not choose between old and amended contrasts by which has the larger score. Overlapping LOSO source sets limit inferential p-values. The source-count study is still confounded by natural optimizer update count.

`python scripts/q13_e006.py` is plan-only. A future, separately authorized cloud run uses `python scripts/q13_e006.py --execute --data-dir /absolute/BNCI-cache`, followed by `python scripts/validate_q13_e006.py --data-dir /absolute/BNCI-cache --device cuda`. This amendment does not launch or publish anything now. Full 27-checkpoint replay and publication must succeed before the new result can inform a paper claim.

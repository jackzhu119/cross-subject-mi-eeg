# Q13 and Q13-E006 post-run statistics

This is a future **analysis-only** step. `scripts/q13_e006_postrun_stats.py` refuses to run until the original Q13 independent report says `passed` with 837 checkpoint replays **and** the Q13-E006 report says `passed` with 27 checkpoint replays. It also requires their completion receipts, checks all 837 original fit metric/prediction hashes against their per-fit receipts and fit-level BA, reconstructs Q13 subject means, rechecks the historical Q5 27-row subject/seed comparator, and checks E006's 15,552 saved predictions against its 27 primary metric rows. It neither fits a model nor changes frozen experiments.

The inference unit is each of the nine held-out BNCI subjects. Three seeds are paired within subject. For k=2/4/6, four predetermined source-identity subsets are averaged within each subject and source count before cross-subject comparison. Source-session `0train` versus `1test` is paired within subject. The distinct E006 versus Q13-E001/Q8_FIXED20 comparison pairs the same subject and seed under the **same actual runtime** and raw MAT hashes. Every negative difference is retained. The original Q5-reuse selection contrast remains reported as a historical cross-run description, not as a clean duration effect if runtimes differ.

The output records every nine-subject paired difference, equal-subject mean, median, sample SD, paired standardized effect, deterministic 10,000-draw subject-bootstrap 95% percentile interval, exhaustive two-sided nine-sign-flip sensitivity, and Holm-adjusted exploratory p-value **within each frozen Q13 family**. The E006 matched-runtime amendment is a separate, single-contrast family and cannot replace the original contrast based on its target score. Source-count trajectories and four-subset spread are exported at their correct repeated-measurement grain; session results preserve every target subject. Input file digests and a digest of the rechecked fit/Q5 inputs are recorded in the analysis receipt; the receipt is not a substitute for immutable Git publication.

`python scripts/q13_e006_postrun_stats.py --results-root results` is the intended command **after** both full validators pass. The script writes a new `results/Q13-E006/postrun_statistics/` child; it does not overwrite Q13 results. A failed prerequisite produces no scientific-statistics receipt. No command in this document authorizes cloud training or Git publication now.

Limitations are not optional: the BNCI target outcomes were previously examined, the nine LOSO training sets overlap, and subset/seed rows are not independent people. Source count also changes the number of training trials and optimizer updates. These are exploratory estimates rather than causal or external-validation claims. The Q5 epoch schedule is historical; E006 does not establish that a new runtime would repeat Q5's inner selection. Bootstrap and sign-flip p-values are fragile at n=9. Reporting only the most favorable subject, seed, subset or condition is prohibited.

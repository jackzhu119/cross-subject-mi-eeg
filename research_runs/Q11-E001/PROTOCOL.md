# Q11-E001: fusion location and capacity (BNCI development only)

This is a post-Q9 **exploratory** experiment. Its matrix and code must be committed and recorded before the first Q11 target prediction. Running Q11 does not constitute preregistration or independent confirmation; subsequent external evaluation needs a separate task-matched protocol frozen without seeing external classification outcomes.

The question is whether decomposition into fixed spectral bands, sharing/duplicating branch parameters, and raw early channel stacking have distinguishable effects. `FOUR_BAND_SHARED` adds spectral resolution without more trainable parameters than Q9's `MU_BETA_SHARED`; `TWO_BAND_INDEPENDENT` doubles branch parameters; `TWO_BAND_EARLY_STACK` lets EEGNet mix mu/beta channels spatially; `BROAD_CAPACITY_MATCHED` tests whether an independent-branch result could instead follow from parameter count. Equal, fixed mean-logit fusion is used wherever there are branches. No learned weights or target-derived fusion rule. An architecture-structure-only parameter census chooses capacity-matched broadband `F1` before any EEG outcome is evaluated. The exact mismatch is disclosed, not silently called exact matching.

All source/target trial identities, labels, flagged-trial inclusion, 22-channel order, 250 Hz sampling, [2.5, 5.5) s epoch, run-local fourth-order zero-phase Butterworth filter, µV conversion, four consecutive-pair source-only inner folds, 40-epoch cap, earliest-minimum mean within-fold CE rank, optimizer, batch size, deterministic setting, selection seed 20260923 and final seeds 20260924–26 remain Q8/Q9-compatible. Each condition has its own 36 source-only inner fits and its own 27 source-only final fits. No normalization, PCA, CSP, source-cleaning or target distributional adaptation is added. The 4-band boundaries are fixed at 8–12, 12–16, 16–22, 22–30 Hz. Target data enter only the final probability calculation. Trial-level cross-entropy is the source-validation criterion; nine held-out subjects, not 27 seeds or 15,552 trials, are the inferential units.

The full batch is 4 × (36 inner + 27 final) = **252 new deep fits**. Comparators Q8 and Q9 are reused, not rerun. The batch cannot pick a winning condition from target scores for later testing on the same BNCI subjects. Report all four conditions and all nine subjects, per-class recall/collapse, mean/SD and paired differences with subject-level uncertainty. Any result should be labelled developmental until an independent, pre-frozen MI-EEG external test is completed. Retain negative results, failures, checkpoints, receipts and selection curves. Filtering is offline and non-causal.

The runner writes per-fit checkpoint, learning curve, fit manifest, architecture receipt, hashes and status; interrupted individual fits restart from their fixed seed while complete hashed fits remain untouched. The independent validator recomputes source splits, selected epochs, trial/probability identity, BA, checkpoint parameter counts and aggregate coverage before a batch completion receipt is accepted.

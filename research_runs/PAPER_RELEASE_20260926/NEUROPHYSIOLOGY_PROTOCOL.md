# Q16-P001: fixed physiological plausibility analysis

**Status:** planned analysis; no physiological results claimed. This is a *non-adaptive* descriptive analysis of sensorimotor patterns, not an extra training/selection stage. Its windows and figures must be committed before calculating physiology–performance associations. Q14-R2FINAL remains a prerequisite for any PhysioNet model-performance correlation.

## Questions and population

1. Do left/right imagery trials show expected class-conditional μ (8–13 Hz) and β (13–30 Hz) ERD/ERS at sensorimotor electrodes, including contralateral C3/C4 structure? Is Cz distinct rather than a universal signal-quality proxy?
2. Are per-subject physiological descriptors associated with frozen cross-subject BA or class collapse, and does the pattern differ between high- and low-generalization people? An association is **not** evidence that the decoder learned that source or that ERD caused generalization.
3. Does the descriptive pattern survive session, artifact-flag and dataset strata without modifying model inputs or excluding difficult subjects?

Use all nine BNCI subjects and both sessions for the four-class study; physiology-performance association is restricted to *left/right* trials so its class definition is coherent. For external binary cohorts include every prespecified eligible subject, but do not make PhysioNet class-performance claims until its independent validator passes. A BA-defined high/low visualization (top/bottom tertile after averaging frozen seeds) is explicitly **post hoc and descriptive**; the primary display is all subjects and a continuous scatter with labels and uncertainty. With only nine BNCI people, do not claim a validated subgroup biomarker.

## Immutable signal-processing recipe

- Read original continuous recordings, hash and identify subject/session/run/cue/event; retain all trials for which the *predeclared* interval exists. Apply the same deterministic fixed montage/channel name mapping and run-local zero-phase filter or spectral estimator across subjects, documenting any notch and edge treatment. Do not average target recordings to fit a decoder transform. Use the physiological analysis pipeline separately from the decoder pipeline.
- Cue-relative **baseline `[-1.5,-0.5)` seconds** and **imagery `[0.5,2.5)` seconds** are selected before inspecting ERD or BA. The shorter imagery interval fits the documented 3-second Cho task. If a recording lacks uncontaminated baseline or an event interval, mark the trial `baseline_unavailable` / `window_unavailable` and publish counts; do not move the window per subject. Baseline interpretation must check previous-trial overlap and dataset event definitions in a metadata-only gate.
- Estimate trial × channel × band power with a fixed Welch specification: one-second Hann segments with 50% overlap, linear detrend, and native-rate frequency bins; integrate only 8–13 Hz and 13–30 Hz in physical frequency units. The code must define band endpoint inclusion once and use it consistently. Convert voltage to power in `µV²/Hz`; report `10·log10(P_imagery/P_baseline)` dB. Negative is ERD, positive is ERS. Preserve per-trial finite-power guard and trial exclusion reason. Use both epoch-level medians and subject-level means as labeled summaries, never trial rows as independent subjects.
- Preselect C3, Cz, C4 and the full frozen 22-channel montage for topography. Use identical color scale, channel positions and interpolation parameters across conditions and cohorts. Avoid inferring source-localized cortical activity from scalp maps. Inspect α/β separately and label hand class, session and event timing.
- Define a signed hand-lateralization descriptor per subject: `0.5 * [(ERD_C3 | right - ERD_C4 | right) + (ERD_C4 | left - ERD_C3 | left)]` in dB. A negative value is more contralateral suppression under this sign convention. Compute it **after averaging trials within subject, hand class and session**; publish both terms so sign mistakes can be audited.

## Outputs, analysis boundary, and failure conditions

Save `trial_power.csv` (identities, hashes, baseline/task power, dB, eligibility reason), `subject_band_summary.csv`, C3/Cz/C4 class/session panels, fixed-scale μ/β topographies, time-frequency descriptive panels if separately specified, per-subject performance–physiology scatter, and a manifest with parameters/software/data hashes. Overlay no target-derived fitted transformation. Report left/right class imbalance and artifact flags; the artifacts themselves are not proof of biological interference removal. If BNCI trial-start/cue relationship or external baseline timing differs from the assumed event map, stop and publish a metadata-only amendment **before** computing any plots. Do not optimize bands, windows, scalp scale, high/low threshold, or significance test after looking at model BA.

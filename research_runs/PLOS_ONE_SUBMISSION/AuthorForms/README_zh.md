官方表格要求在 Methods 中注明研究访问日期（日/月/年）及作者是否接触能识别参与者身份的信息，并在表中填写对应的实际行号。本文使用已有公开 EEG，可先据记录整理各来源的研究访问日期和使用范围，再由本人确认适用答案及措辞。

- **原始访问记录**：提供者下载记录、原实验记录、原始数据登记表或同期日志，可以帮助核实本研究何时取得和使用数据。
- **后续技术记录**：R2 上传、云服务器下载、迁移、备份、导出或重新观察元数据的时间，只能证明那次操作发生，不自动等于首次研究访问日期，也不证明期间没有其他访问。
- **身份信息**：提供者的被试编号、去标识化数据及公开人口学信息，与姓名/联系方式等直接识别信息不同。由本人确认自己实际可以访问哪些字段、是否可能识别参与者及访问范围；不要仅凭“公开数据”或当前派生 ZIP 就声明完全不存在识别风险。

# 论文1：源训练数据扩充与稳健选轮实验

本包是可执行的新实验任务。正式数据规模为 **BNCI 9 人 + Yang/WBCIC-SHU 二分类 51 人 = 60 名源被试、33,192 个不同左右手试次**。它从固定公开版本下载原始数据、生成输入、完成源内选择和最终训练，然后进行外部评估及统计。这里的样本量是待全量质量核验的预设清单；合成测试和小样读取不计作全量训练完成。

## 1. 为什么选择这套新增数据

Yang 等的 *A multi-day and high-quality EEG dataset for motor imagery brain-computer interface* 发表于 **2025-03-23**，论文 DOI：[10.1038/s41597-025-04826-y](https://doi.org/10.1038/s41597-025-04826-y)。本包使用作者 Figshare **v5，2024-12-06** 的原始文件：[10.25452/figshare.plus.22671172.v5](https://doi.org/10.25452/figshare.plus.22671172.v5)，许可 CC BY 4.0。数据采集年份为2019；不能称为2025新采集队列。

只取2C左右手任务的51人、每人3天、每天200试次，新增30,600试次。实际ZIP清单已核实为 sub-001 至 sub-051、153个session、306个原始信号/事件文件。ZIP中的README与participants表保留旧人数，代码不依赖那些行数推断研究人口。不把3C组或同一数据的NEMAR镜像重复计为新增独立被试。

近期另一个候选是 *A Synchronous EEG-fNIRS Motor Execution and Imagery Dataset*，Scientific Data 2026，DOI：[10.1038/s41597-026-08298-6](https://doi.org/10.1038/s41597-026-08298-6)。作者报告50名健康被试，官方数据在 [ScienceDB](https://doi.org/10.57760/sciencedb.30795)，[作者代码](https://github.com/wxc198929/SEFMEID-CODE) 同时处理MI、ME和静息。它的原始清单、32通道兼容性、任务标签与无需人工介入的下载链还未完成本包同等程度的核验，**本任务不会自动把它混入S60**。不能把ME样本直接当MI扩样。

Guttmann/Flury 31人MI可作后续候选：[论文](https://doi.org/10.1038/s41597-025-04861-9)、[作者数据](https://doi.org/10.7303/syn64005218)、[转换镜像](https://zenodo.org/records/18970793)。原文推荐的全局坏/桥接通道排除含FC3；纳入会进一步改变共同通道。其2026镜像日期也不是新队列的采集日期。本轮先固定可核验的Yang扩源。

## 2. 这次要回答的研究问题

**在相同优化更新预算下，增加独立源被试和源试次，能否改善外部被试较弱类别的识别可靠性？源内关注尾部的选轮规则是否仍有价值？**

| 条件 | 源被试组成 | 不同源试次 | 每条神经轨迹更新数 |
|---|---|---:|---:|
| S9 | BNCI 9人 | 2,592 | 5,120 |
| S29 | BNCI 9人 + 固定Yang 20人 | 14,592 | 5,120 |
| S60 | BNCI 9人 + Yang 51人 | 33,192 | 5,120 |

Yang20人由事先固定种子生成，嵌套于51人组。不能挑外部表现较好的20人，也不能把同一人的不同天数分到训练与验证两边。该一个中间子集是预设阶梯对照，不代表所有20人子集的变异。

“一个epoch”在本任务中严格定义为 **128次参数更新、batch64**，总40个候选epoch。它不是把每个数据集遍历一遍。每批先等概率选择源数据集，再选择被试、类别和试次；抽样有放回。有Yang时BNCI/Yang各占期望50%，避免51人队列按试次数压倒9人队列。不同组的可用样本不等，但最大优化预算相等。被选检查点的实际更新数仍可能不同，输出会完整记录。

主比较同时改变了队列来源、人数和不同试次数，不能解释成纯粹的“多一个人的因果效应”，也不能据此保证扩源一定改善结果。

## 3. 数据和模型合同

### 真实共有18通道

`Fz FC3 FC1 FCz FC2 FC4 C5 C3 C1 Cz C2 C4 C6 CP3 CP1 CP2 CP4 Pz`

Yang没有CPz，因此本包删除该通道，不插值或补零。BNCI S9基线也以相同18通道完整重训；历史19通道成绩不能直接放进这张扩源对照表。

三个固定频带为8–30、8–13、13–30 Hz；共同平均参考只使用这18个通道。每个原生六秒上下文应用四阶Butterworth SOS、固定odd pad27和固定二进制系数/初始状态，再重采样至160Hz。最后输出每试次3×18×320点。正式合同及250/512/1000Hz系数在 `config/filter_bank18.json`。

### Yang单位与时序的明确处理

实读的Yang原始BDF单位字段是字面 `?V`，与一个现有MOABB适配器的nV说明不同。本包不猜它代表µV或nV。按BDF数字/物理范围校准后，三个数据集都应用同一个预设单试次归一化：每个view/channel减本试次时间均值，三view共同除以本试次broad全部18×320点的RMS。输出为无量纲。该公式消除共享的正单位倍率，不使用其他试次或外部被试集合的统计量，且不能支持绝对物理幅度的研究结论。

作者ZIP内预处理代码在任务标记后提取[0,4]秒；MOABB解释则对应[1.5,5.5]秒。原标记是否在视频提示开始还是MI开始仍存在语义差异。因此Yang固定使用 **原始1/2标记后[2,4)秒**、上下文[0,6)秒；它处于这两种已记录解释的MI交集中。计算用的+1.5秒锚点只是分析锚点，不写成已证实的MI onset。BNCI和Dreyer使用已核MI锚点后[0.5,2.5)秒；不同数据集的实际MI内部相位不声称完全相同。

### 神经模型与传统模型

两个神经流程均调用官方固定 `braindecode==1.5.1` 的EEGNet：F1=8、D=2、F2=16、kernel64、dropout0.25；18×320输入时实测1,714个参数。BROAD只用8–30Hz；MU_BETA_SHARED将mu/beta送入同一个骨干并平均logits后计算交叉熵。二者是同一架构家族的两种流程，不是独立架构。Adam学习率0.001，无scheduler、weight decay、AMP或目标侧BatchNorm更新。

传统对照使用固定CSP+shrinkage LDA：CAR后先用固定Helmert矩阵降至17维；源内按人、队列平衡估计类别协方差，固定0.1收缩、2+2个CSP分量；LDA使用事先固定的平衡源样本重采样。无超参数搜索。其结果独立汇总，不混入神经选择器的主检验家族。CSP原始方法参见 [Ramoser等，2000](https://doi.org/10.1109/86.895946)，协方差收缩背景参见 [Ledoit和Wolf，2004](https://doi.org/10.1016/S0047-259X(03)00096-4)。人员/队列等权及8192行有放回重采样是本研究的固定配置，不声称是新算法，也不把重采样行数计为新增独立数据。

## 4. 源内选择、外部评估和统计

每组固定5个按数据集分层的**整人**验证折，3个验证种子、2个神经流程。90条源验证轨迹完成后，8条规则分别选轮：fixed20、mean_ce、mean_rank、mean_ba、tail_ce、tail_ba、mean_min_recall、tail_min_recall。定义和决胜规则在 `p1_select.py`。

验证先在每个被试、每个种子内计算指标，再跨3种子平均到被试；数据集等权、各数据集内被试等权。tail取精确1/3概率质量，边界使用分数权重，不能用简单ceil人数替代。较弱类召回必须先对每个种子求两类recall的最小值，再平均种子。

全部选轮写入不可静默更改的 `selection_freeze.json`。之后每组2流程×3最终种子，共18条全源轨迹都训练到40轮，再复用已选检查点。**合计108条神经轨迹；8条规则的别名复用不计为8次独立训练。** CSP另有9个源内拟合。

外部评估保留Dreyer 85人：NEMAR `nm000250 v1.0.5/sourcedata` 的两个acquisition EDF，预设排除提供者全局sub-17和sub-41，各剩余人80试次，总6,800试次。镜像被提供者声明为上游EDF的未改写副本；本包固定其SHA，并不声称它等于原始Zenodo GDF字节。174个原始文件清单都下载核验，排除人不进入模型评估。

新的目标原始下载、预处理和预测安排在所有源选择冻结、所有最终源训练完成之后。外部标签不参与选轮、阈值、模型、归一化或超参数。历史Dreyer使用情况作者回答“不确定”，所以本次仍标记为**探索性外部验证**。

预设主终点：S60 BROAD tail_min_recall与S9相同流程之间，每名外部被试较弱类召回率的差。统计单位为85名被试，先平均3个种子的被试指标。报告配对双侧t检验、均值差、95%CI以及10,000次被试配对bootstrap区间。三个次要对比统一Holm校正：S60 tail规则对mean_ba规则；S60对S29；S60对S9的balanced accuracy。全部其他选择器和共享流程结果保留为描述性分析，不重新挑选“获胜主结果”。

本包只新增这块扩源实验，不把它冒充整篇论文已具备全部投稿证据。原计划中的Cho/Lee等其他外部复核，以及与最近相似方法的最终文献比较，应在解释本次结果时继续处理。

## 5. RunPod运行

选择 **Linux x86_64、NVIDIA GPU、至少16GB系统内存（建议32GB）、至少120GB网络持久卷挂到/workspace** 的Pod。单卡即可；24GB显存足够宽裕，当前代码不需要多卡。容器需有python3、bash、flock、nvidia-smi；NVIDIA驱动需支持CUDA12.8运行时。可以使用RunPod的PyTorch模板；启动器会在独立目录安装固定环境，模板现有Python包不参与训练。

代码目录就位后：

```bash
bash /workspace/paper1_expansion/code/bootstrap.sh
```

它会立即转入后台，依次安装固定uv/Python3.12.12和CUDA12.8依赖，执行本地合同测试，再下载、核验、训练、评估、出图并打包。Python依赖由 `uv.lock` 固定，正式环境默认不重新解析版本。uv二进制及下载轮子都有固定SHA256。

查看进度：

```bash
tail -f /workspace/paper1_expansion/run.log
```

查看运行状态：

```bash
cat /workspace/paper1_expansion/runs/expansion18_v1/status.json
```

中断后，在保留同一持久卷和同一代码版本的Pod上，重跑同一bootstrap命令。已完成的原始文件校验后复用；BNCI/Dreyer支持普通HTTP部分续传；Yang保留已完成成员，中断的单个压缩成员从该成员开头重下。每个已完成epoch保存模型、优化器、Python/NumPy/Torch/采样器及CUDA RNG。代码、数据或依赖变化会要求使用新运行目录，不能把两个不同协议接成一条结果轨迹。跨不同GPU型号只记录硬件变化，不承诺逐位相同。

进程完成后 `status.json` 显示 `COMPLETE`。程序不调用RunPod开关机API；结束后由你处理Pod。网络卷的正确挂载以RunPod控制台为准：[官方存储说明](https://docs.runpod.io/pods/storage/types)。

## 6. 下载量和结果

Yang选择成员传输约43.98GB、解压68.04GB。代码通过官方ZIP的HTTP Range读取所需成员，不额外保存整65.63GB ZIP。开始前动态检查剩余解压空间和15GiB保留空间。固定ZIP文件长度、中央目录SHA，每完整成员校验CRC与长度并记录SHA256；**不称为已校验整个ZIP的MD5**。

最终下载文件：

```text
/workspace/paper1_expansion/runs/expansion18_v1/paper1_expansion_results.zip
```

其中包含中文结果报告、全部源验证曲线、源选轮冻结、输入及环境审计、检查点映射、979,200行神经逐试次预测、逐被试和逐条件统计、预设比较及PDF/PNG图。CSP结果另表列出。原始EEG与大处理缓存留在持久卷，不装入结果ZIP；训练检查点也留在 `runs/expansion18_v1/checkpoints`。

出现数据长度、人数、类别、通道、SHA、环境或非有限loss问题时，程序保留已有数据与证据并报错，不以静默删人、删trial、换输入或重选外部最佳结果来“跑通”。

## 7. 验证范围和下一步

交付前已经验证依赖解析、实际官方模型CPU前向和更新、完整RNG恢复；数据方面实读BNCI01两会话、Dreyer A01两个acquisition、Yang完整小事件文件和一个真实原始trial。干净Python3.12.12环境中的全部72个非GPU依赖版本与生产锁文件一致；PyTorch/torchaudio明确使用同版本CPU构建进行这些本地检查。最终整包 **57项测试通过，0失败、0错误、0跳过**，包括下载/恢复门禁、传统基线编排及完整报告导出。完整验证记录随代码的 `validation/` 提供。未执行本任务的全51人Yang数据处理、108条正式神经轨迹或RunPod GPU全流程，最终科研结论须由实际输出决定。

第一次完整运行后，优先查看主差值及区间、逐人受益/受损分布、S29至S60的趋势，以及mean_ba对照。若只平均BA变高而较弱类召回不改善，应收缩论文主张；若扩源负迁移，保留并解释队列、时段和采样策略限制。扩样本本身不自动构成新算法创新，本任务提供的是可检验的跨队列可靠性证据。

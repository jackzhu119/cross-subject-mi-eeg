## Why E005 is separate from Q14

Lee's published MOABB channel catalogue does not list `FCz`, which Q14's 22-channel source model requires. Q15-E005 proposes a **new** BNCI-trained 21-channel source model, with the single channel `FCz` removed in Q14 order and a 2-second cue-relative `[0.5,2.5)` window. It does not edit Q14 checkpoints and must never be described as an exact Q14 checkpoint transfer. The raw channel and cue contracts in both external cohorts remain unverified.

The fixed source stage comprises BROAD_EEGNET and MU_BETA_SHARED, each with four BNCI source-subject inner fits and three final fixed-seed fits (14 neural fits), plus one CSP4+LDA all-source fit. Selection uses only BNCI source subjects and the frozen within-fold cross-entropy rank rule. It cannot select a model, seed, channel subset, or filter using Lee/Cho outcomes. All 18 BNCI MAT bytes must match the existing Q8 source provenance before loading.

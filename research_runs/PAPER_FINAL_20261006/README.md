# Frozen scientific source materials

The current manuscript and submission materials are in [`../PLOS_ONE_SUBMISSION/`](../PLOS_ONE_SUBMISSION/), prepared for **PLOS ONE**. This directory is a source/evidence collection, not a submission package.

Saved numerical tables, scientific figures, metadata and audit inputs are retained for traceability. Files protected by the scientific preservation manifest remain byte-identical. Structured text and reference metadata are retained only as source inputs for the current editorial conversion. Historical editorial exports and delivery receipts are available through [the immutable predecessor snapshot](https://github.com/jackzhu119/cross-subject-mi-eeg/tree/0c7146895dc46850e4fe7db38bd69d9aea2b41c3).

Read the active PLOS ONE reproducibility and submission instructions before using any file. No EEG training, prediction inference or physiology experiment was performed as part of this editorial transition.

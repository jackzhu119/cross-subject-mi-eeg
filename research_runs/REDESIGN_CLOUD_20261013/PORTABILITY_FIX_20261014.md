# Local-lock and portable bootstrap correction — 14 October 2026

Observed external terminal report: CUDA template precheck returned `GPU runtime found. No fitting has started.`, followed by generic `BlockingIOError` before price/credential/job output. In the reported release, the first supervisor operation was a nonblocking flock on `/workspace/mi-eeg-cloud/.launch.lock`. This report does not independently establish whether the old shared filesystem rejected locking or another launcher held it; no current Pod state was obtained. The particular failing invocation cannot have passed that first lock into source execution. Another existing process is not presumed absent.

Correction: bootstrap, launcher, supervisor, source and inference process locks now use owner/permission/symlink-checked private local `/tmp` files, keyed by canonical working/job paths. Real contention remains blocking and reports scope/PID without credentials. Lock files are not deleted as a recovery method. A persistent execution registration, original budget origin and exact runtime/machine/UUID checks remain; a new code revision does not silently replace a registered scientific job. Old running processes are checked locally without printing their command arguments. Local mutexes do not establish distributed locking across separate Pods sharing a volume.

The same immutable command now runs on Linux NVIDIA hosts with Python3.11/3.12, git, venv, driver and internet. Optional `--work-dir` selects persistent storage. An exact existing PyTorch2.8.0/torchaudio2.8.0 CUDA12.8 runtime is reused only after package/GPU verification; otherwise an isolated fixed runtime is installed. Setup uses the original eight-hour clock and terminates the setup process group at its deadline. Actual provider billing remains manually controlled.

Scope is operational only. No frozen Q1–Q16 outcome, cohort roster, preprocessing rule, architecture, seed, optimizer, training-duration selection rule, contrast, confidence interval or p-value was altered. No scientific fit or target model output was run during this correction. Previous release commits remain available; no history is rewritten.

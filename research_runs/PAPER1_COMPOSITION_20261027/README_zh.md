# 论文1：源队列构成 × 尾部风险目标后续实验

本轮直接检验：**在相同独立试次数和优化预算下，源队列构成是否改变 TAIL 相对 ERM 的弱类别收益？** 同时保留全部可用试次条件、Yang-only、五组 S29 子集和传统方法参照。完整冻结方案见 [PROTOCOL.md](PROTOCOL.md)，参数见 [config/study.json](config/study.json)。

这是查看上一轮结果后设计的后续实验。结果方向由新实验决定；所有预定条件和正、负、无显著差异结果均保留。

## 实验规模

| 内容 | 固定设计 |
| --- | --- |
| 数据 | 复用已完成的 BNCI9 + Yang51 源数据；Dreyer85 为曾暴露的探索性外部评估 |
| 条件 | S9 1个，Y51 2个，S60 2个，5组 S29 各2个，共15个 cell |
| S29 | 每组从原5个共同外层折各固定选4名 Yang；全局20名 Yang + 9名 BNCI |
| 试次条件 | 全部可用；或等总独立试次，混合源各队列占一半 |
| 神经方法 | ERM、TAIL；每次固定40轮、5,120更新，无 inner validation、无选轮 |
| 每批 | 4人 × 2类 × 16试次 = 128；混合源每队列2人 |
| 神经任务 | 450开发 + 90最终 = 540次 |
| 传统参照 | 同一白名单的确定性加权 CSP–regularized LDA，75开发 + 15最终 = 90次 |
| 合计 | 630项任务；S9 all/matched 为同一任务别名，不重复训练 |

所有 cell 共用旧项目的5个外层测试人分组。每折均评价同一批测试人，包括只用 S9 训练时的 Yang 测试人、只用 Yang 训练时的 BNCI 测试人。最终全部条件均评价85名 Dreyer，不能称为全新盲测。

等总试次设计属于**固定预算的源构成替换**，不能将其解释成原有试次完全保留的单纯扩增。最终每个 matched 条件共2,592个独立试次。主比较是 matched 条件上 `TAIL−ERM` 在 S60 与 S9 间的交互；另有9个源次比较统一 Holm 校正，外部对应10个比较统一作为探索性 Holm 家族。五组 S29 重叠，不当作五批独立受试者。

## 中断、续跑和进度

训练按耗时定期保存，保留两代 checkpoint；保存模型、优化器及动量、采样器、随机状态、epoch/step 和实际启用的 AMP 状态。固定40轮不选择最佳轮次。任务存在有效完成记录则跳过，未完成则继续其原 checkpoint。

模型训练完成后的评价按参与者/会话片段落盘，并绑定模型身份；评价中断后复用现有片段，不重新训练。USR1 提前通知时保存后尝试 Slurm requeue；学校不允许自动 requeue 时，再执行同一启动命令。用户主动取消不自动复活。某项独立任务失败保留真实 traceback，其余可运行项继续；修复后只补未完成项。

运行日志每约30秒报告实际阶段、step/optimizer updates 和已评价样本数。`RUNNING` 或心跳时间变化不单独证明参数更新，应看到 step 或更新数增加，或已完成任务数增加。默认约180秒独立同步本轮进度与已完成统计到 GitHub；网络、限流或上传失败后台重试，不阻断模型训练。

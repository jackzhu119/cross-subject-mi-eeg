This is an operational amendment after source-only failure diagnosis. It is not
the original preregistration, a new decoder, a tolerance change, or a scientific
outcome. The historic generator's BLAS/machine identity remains unknown.

The actual native Haswell source reconstruction was stopped before any fits.
Prior source-only bounded comparisons localized the difference to SOS initial

## Registered numerical rule

`config/numerical_execution_v1.json` has SHA256
`04f562ddddc4e5019e56240b980d6d9c2d78645860857a5ab0d9746e788ae476`.
It records binary64 SOS and initial states as exact hex values and array hashes
for 250 and 512 Hz, all three bands. The 250 Hz states are identical to the
already observed current SkylakeX coefficient-only evidence at commit
`5f20b35ab720f05ee208d4ceb12d582148719bf8`. The 512 Hz table is one coefficient-only
extension under the same installed NumPy 2.3.5 / SciPy 1.17.0, generated before
target rebuilding without target EEG or performance. This does not establish the
historical generator's backend. No alternative 512 profile will be selected from
target outcomes or target acceptance failures.

`scripts/formal_core_inputs.py` is a new explicit execution module. It retains
the original loader byte-for-byte and copies its population/order and transform
equations into a versioned adapter. It applies the registered state to EVERY
trial, EVERY band, both native rates: no exceptional trial list, no element
editing, no hash-based branch choice, no state learned from data, no monkeypatch
of the old loader. CAR19, Butterworth SOS, odd pad27, forward/reverse filtering,
resample_poly, windows and float32 conversion retain their original order.
Unregistered rate/band, versions, numerical override, SOS/state identity or
frozen reference changes fail closed. Bitwise portability is conditional on the
complete exact gates, not claimed for arbitrary platforms.
